# Start here: working on the Bol-loop classification

This is a research workspace, not just a list of announcements. Its goal is to let a new human or AI researcher understand the target, choose a precise task, recover the evidence, and contribute a result without access to private discussions.

**Readiness:** you can start on several published constructions today. The entire programme is not yet a self-contained public mirror: some proof closures and recent developments still need reconciliation. A catalogue summary is a route to a proof, not a substitute for one. See [the dated coverage audit](COVERAGE_AUDIT.md).

## The target, precisely

Classify finite simple proper **left Bol loops**, up to loop isomorphism, with no order or exponent restriction. A successful classification provides:

1. Explicit structural data and an admissibility condition.
2. Soundness: every admissible datum constructs a loop of the required kind.
3. Exhaustion: every target loop comes from some datum.
4. An exact equivalence relation on data which is equivalent to loop isomorphism.

The broader all-simple programme includes the established group and Moufang baselines. The new challenge is the proper, non-Moufang part. Exhaustive table search is a check, not the desired structural answer. Efficient generation is a subsequent goal.

## Essential vocabulary and convention traps

- A **loop** has an identity and unique solutions to both `ax=b` and `ya=b`. **Simple** means no nontrivial proper normal subloop, not no proper subloop.
- **Left Bol:** `x(y(xz))=(x(yx))z`. **Moufang:** `(xy)(zx)=(x(yz))x`; **proper Bol** here means non-Moufang.
- Passing to the **opposite** multiplication converts left to right Bol. This transports classification results; it does not assert that a loop is isomorphic to its opposite.
- An **isomorphism** preserves one binary operation. An **isotopy** uses three bijections relating two multiplications. A **G-loop** is isomorphic to all its loop isotopes.
- A **left Bruck loop** is left Bol with the automorphic inverse property `(xy)^-1=x^-1 y^-1`. Being Bruck and having a Bruck isotope are distinct assertions.
- `LMlt(Q)` is generated by left translations; `Mlt(Q)` is generated by left and right translations. Loop simplicity does not make either group simple, and a theorem about one cannot be silently transferred to the other.
- A **folder/envelope** encodes the loop by a group, identity stabilizer and distinguished translations. Our canonical results retain those marked data. An abstract group or composition-factor list alone is not the same object.
- The **solvable radical**, **socle**, and **canonical inversion** belong to the specified group model. “Radical-free,” “paired inversion,” and “nonpermuting socle” are substantive restrictions, not labels that cover every case.
- A finite certificate checks its stated finite inputs. A universal theorem still needs a proof. A review of one section does not automatically review later appendices.

## First reproducibility exercise

Clone this public repository, record its commit, and run the two small checks supplied with the original existence packet:

```sh
git clone https://github.com/Mira-Cult/math.git
cd math
git rev-parse HEAD
cd notes/finite-simple-bol-loops/packet
python3 code/verify_odd_rigid_center.py
python3 code/independent_bch_section_check.py
```

Read the scripts before running them. Record your Python version, commands, full output and elapsed time. These checks validate arithmetic and local section calculations, not all elements of the enormous loop and not a universal proof. Other files may require GAP or additional libraries: use the exact manuscript's instructions rather than infer an environment from this example.
