### 1. Self-Pairedness of Rank-3 `AS` Groups & Spectral Trace Integrality Obstruction

1. **Self-pairedness**:
   Suppose $`P \le \mathop{\mathrm{Sym}}\nolimits(\Omega)`$ ($`|\Omega| = n \ge 3`$) is transitive of rank $`3`$ with non-self-paired orbitals $`\Delta_2 = \Delta_1^\top \neq \Delta_1`$. If $`|P|`$ were even, an involution $`1 \neq u \in P`$ would move some $`\alpha \in \Omega`$ to $`\beta = u(\alpha) \neq \alpha`$ and map $`(\alpha, \beta) \mapsto (\beta, \alpha)`$, placing $`(\alpha, \beta)`$ and $`(\beta, \alpha)`$ in the same $`P`$-orbital, contradiction. Thus $`|P|`$ is odd (in fact $`P \le \mathop{\mathrm{A\Gamma L}}\nolimits_1(p^d)`$ with $`p^d \equiv 3 \pmod 4`$ by W. M. Kantor, *Math. Z.* **124**, 1972, 261–265, Theorem 1). Since every finite nonabelian simple group has even order (Feit–Thompson 1963), every primitive rank-$`3`$ `AS` group has self-paired orbitals $`\Delta_i = \Delta_i^\top`$, forming a connected undirected strongly regular graph $`\Gamma = \mathrm{srg}(n, k_1, \lambda, \mu)`$ ($`n = 1 + k_1 + k_2`$, $`\mu \ge 1`$).

2. **Spectral Trace Integrality**:
   By A. E. Brouwer and H. Van Maldeghem, *Strongly Regular Graphs*, Cambridge Univ. Press, 2022 (`[BvM22]`), Theorem 1.3.1, in every non-conference SRG the discriminant $`\Delta_{\mathrm{disc}} := (\lambda - \mu)^2 + 4(k_1 - \mu)`$ divides $`((n - 1)(\mu - \lambda) - 2 k_1)^2 \neq 0`$ and is an integer square, giving integer eigenvalues $`k_1 > r > 0 > s`$ of multiplicities $`1, f, g \in \mathbb{Z}_{>0}`$ with $`1 + f + g = n`$ and $`k_1 + f r + g s = 0`$. Decompose $`\mathbb{C}^n = \mathbb{C}\mathbf{1} \perp V_r \perp V_s`$ into the eigenspaces of the symmetric adjacency matrix $`A_1`$. Any $`g \in \mathop{\mathrm{Aut}}\nolimits(\Gamma)`$ has permutation matrix $`P_g`$ commuting with $`A_1`$, so $`\chi_r(g) := \mathop{\mathrm{Tr}}\nolimits(P_g|_{V_r})`$ and $`\chi_s(g) := \mathop{\mathrm{Tr}}\nolimits(P_g|_{V_s})`$ satisfy
   $$1 + \chi_r(g) + \chi_s(g) = \mathop{\mathrm{Tr}}\nolimits(P_g) = |\mathop{\mathrm{Fix}}\nolimits_\Omega(g)|, \qquad k_1 + r \chi_r(g) + s \chi_s(g) = \mathop{\mathrm{Tr}}\nolimits(P_g A_1) = \sum_{\omega \in \Omega} (A_1)_{\omega, g(\omega)}.$$
   - If $`g_1`$ is $`\Delta_1`$-UOD, $`\mathop{\mathrm{Tr}}\nolimits(P_{g_1}) = 0`$ and $`\mathop{\mathrm{Tr}}\nolimits(P_{g_1} A_1) = n`$; substituting $`\chi_s(g_1) = -1 - \chi_r(g_1)`$ gives $`(r - s)\chi_r(g_1) = n - k_1 + s = k_2 + 1 + s`$, so $`\chi_r(g_1) = c_{\Delta_1} = \frac{k_2 + 1 + s}{r - s}`$.
   - If $`g_2`$ is $`\Delta_2`$-UOD, $`\mathop{\mathrm{Tr}}\nolimits(P_{g_2}) = 0`$ and $`\mathop{\mathrm{Tr}}\nolimits(P_{g_2} A_1) = 0`$, giving $`(r - s)\chi_r(g_2) = s - k_1`$, so $`\chi_r(g_2) = c_{\Delta_2} = \frac{s - k_1}{r - s}`$.
   Since $`P_g`$ has finite order, all eigenvalues of $`P_g|_{V_r}`$ and $`P_g|_{V_s}`$ are roots of unity (algebraic integers of modulus $`1`$), forcing $`\chi_r(g) \in \mathbb{Q} \cap \overline{\mathbb{Z}} = \mathbb{Z}`$, $`|\chi_r(g)| \le f`$, and $`|-1 - \chi_r(g)| \le g`$. By `0323-finite-simple-non-moufang-bol-loops:C0008` Lemma 2.1(1), any loop on $`\Omega`$ with $`\mathop{\mathrm{Mlt}}\nolimits(Q_{\mathrm{loop}}) \le \mathop{\mathrm{Aut}}\nolimits(\Gamma)`$ requires both $`\Delta_1`$-UOD and $`\Delta_2`$-UOD left translations.

### 2. $`\mathbb{F}_3`$-Hurwitz–Paige Moufang Collapse on $`\mathrm{NO}_{2m}^\varepsilon(3)`$ ($`m \ge 3`$)

Let $`(V, Q)`$ ($`V = \mathbb{F}_3^{2m}`$, $`m \ge 3`$, $`B(u, v) = Q(u + v) - Q(u) - Q(v)`$ so $`B(v, v) = -Q(v)`$) have type $`O_{2m}^\varepsilon(3)`$, fix $`\delta \in \{\pm 1\}`$, and put $`S_\delta = \{v \in V : Q(v) = \delta\}`$ and $`\Omega_{\varepsilon, \delta} = \{[v] \in \mathbb{P}(V) : v \in S_\delta\}`$.

1. **Exact stabilizer $`P_{\max} = \mathop{\mathrm{PO}}\nolimits(V, Q)`$**:
   For $`(2m, \varepsilon) \neq (8, +)`$, $`\mathop{\mathrm{Aut}}\nolimits(\mathop{\mathrm{P\Omega}}\nolimits_{2m}^\varepsilon(3)) = \mathop{\mathrm{PGO}}\nolimits_{2m}^\varepsilon(3)`$, and any similarity $`\hat{g} \in \mathop{\mathrm{GO}}\nolimits(V, Q) \setminus O(V, Q)`$ has multiplier $`-1`$, swapping the disjoint sets $`\Omega_{\varepsilon, +1} \leftrightarrow \Omega_{\varepsilon, -1}`$; hence $`P_{\max} = \mathop{\mathrm{PO}}\nolimits(V, Q)`$. At $`(2m, \varepsilon)=(8,+)`$, use the full graph automorphism group instead of an unverified triality-class count. BvM's author manuscript §10.78, p. 331, identifies the full automorphism group of $`\mathrm{NO}_8^+(3)`$ as $`\mathop{\mathrm{P\Omega}}\nolimits_8^+(3):2^2`$. The natural image $`\mathop{\mathrm{PO}}\nolimits_8^+(3)=O_8^+(3)/\{\pm I\}`$ preserves this graph and has that order, since $`-I\in\Omega_8^+(3)`$ and $`|O_8^+(3):\Omega_8^+(3)|=4`$. Thus it is the full graph group, and every rank-three group with these orbitals is contained in it.

2. **Projective-collinearity sign alignment $`\hat{L}_x(y) = \hat{R}_y(x)`$**:
   Fix loop identity $`[e] \in \Omega_{\varepsilon, \delta}`$ ($`e \in S_\delta`$). Each $`L_{[x]}, R_{[y]} \in \mathop{\mathrm{PO}}\nolimits(V, Q)`$ ($`x, y \in S_\delta`$) lifts uniquely to $`\hat{L}_x, \hat{R}_y \in O(V, Q)`$ with $`\hat{L}_x(e) = x`$ and $`\hat{R}_y(e) = y`$ ($`\hat{L}_{-x} = -\hat{L}_x, \hat{R}_{-y} = -\hat{R}_y`$), satisfying $`\hat{L}_x(y) = \varepsilon(x, y)\hat{R}_y(x)`$ for a unique sign $`\varepsilon(x, y) \in \{\pm 1\}`$ ($`\varepsilon(-x, y) = \varepsilon(x, -y) = \varepsilon(x, y)`$, $`\varepsilon(x, e) = +1`$).

   For any $`y_1, y_2 \in S_\delta`$ with $`[y_1] \neq [y_2]`$ and $`B(y_1, y_2) = -\delta`$, we have $`Q(y_1 + y_2) = \delta + \delta - \delta = \delta`$, so $`y_1 + y_2 \in S_\delta`$ and $`\varepsilon(x, y_1 + y_2)\hat{R}_{y_1 + y_2}(x) = \varepsilon(x, y_1)\hat{R}_{y_1}(x) + \varepsilon(x, y_2)\hat{R}_{y_2}(x)`$ for all $`x \in S_\delta`$. Hence $`S_\delta \subseteq W_{+,+} \cup W_{-,-} \cup W_{+,-} \cup W_{-,+}`$, where $`W_{\sigma_1, \sigma_2} := \ker(\hat{R}_{y_1 + y_2} - \sigma_1 \hat{R}_{y_1} - \sigma_2 \hat{R}_{y_2})`$. Because the operators defining $`W_{\tau_1, \tau_1}`$ and $`W_{\tau_2, -\tau_2}`$ differ by $`\mp 2\hat{R}_{y_1}`$ or $`\mp 2\hat{R}_{y_2} \in O(V, Q)`$ (invertible), $`W_{\tau_1, \tau_1} \cap W_{\tau_2, -\tau_2} = \{0\}`$ for all $`\tau_1, \tau_2 \in \{\pm 1\}`$, so $`a + b \le 2m`$ where $`a = \max(\dim W_{+,+}, \dim W_{-,-})`$ and $`b = \max(\dim W_{+,-}, \dim W_{-,+})`$. Any hyperplane $`W \subset V`$ satisfies $`|W \cap S_\delta| \le 3^{2m-2} + 3^{m-1}`$ by hyperbolic-plane induction, and any subspace of dimension $`d \le 2m - 2`$ satisfies $`|W \cap S_\delta| \le 3^d - 1`$. If all four $`W_{\sigma_1, \sigma_2}`$ were proper subspaces ($`\max(a, b) \le 2m - 1`$), then $`\sum |W_{\sigma_1, \sigma_2} \cap S_\delta| \le \max\{2(3^{2m-2} + 3^{m-1}) + 4,\; 2(3^{2m-2} - 1) + 16,\; 4 \cdot 3^{2m-3}\} < 3^{m-1}(3^m - 1) \le |S_\delta|`$ for every $`m \ge 3`$. Explicitly, with $`X=3^{m-1}\ge 9`$, the differences between $`3X^2-X`$ and the three upper bounds are $`X^2-3X-4`$, $`X^2-X-14`$, and $`5X^2/3-X`$, all positive. The hyperplane bound follows from the standard quadratic-form counts: its radical has dimension at most one, and counting in the nondegenerate quotient gives at most $`3^{2m-2}+3^{m-1}`$ vectors of norm $`\delta`$. This proves the all-$`m`$ inequality; the finite script checks do not. Contradiction. Thus some $`W_{\sigma_1, \sigma_2} = V`$; evaluating at $`e`$ gives $`(1 - \sigma_1)y_1 + (1 - \sigma_2)y_2 = 0`$, forcing $`\sigma_1 = \sigma_2 = +1`$ and $`\hat{R}_{y_1 + y_2} = \hat{R}_{y_1} + \hat{R}_{y_2}`$. Substituting back gives $`(\varepsilon(x, y_1 + y_2) - \varepsilon(x, y_1))\hat{R}_{y_1}(x) + (\varepsilon(x, y_1 + y_2) - \varepsilon(x, y_2))\hat{R}_{y_2}(x) = 0`$; the vectors $`\hat{R}_{y_1}(x),\hat{R}_{y_2}(x)`$ are linearly independent: their projective classes are $`[x]*[y_i]`$, distinct by left cancellation. Therefore $`\varepsilon(x,y_1)=\varepsilon(x,y_2)`$. The case $`B(y_1,y_2)=+\delta`$ reduces to the displayed case by replacing $`y_2`$ by $`-y_2`$. Thus the signs agree whenever $`[y_1] \neq [y_2]`$ and $`B(y_1, y_2) \neq 0`$. If $`B(y_1, y_2) = 0`$, choosing $`u \in \{y_1, y_2\}^\perp`$ ($`\dim = 2m - 2 \ge 4`$) with $`Q(u) = -\delta`$ gives $`z := y_1 + y_2 + u \in S_\delta`$ with $`B(z, y_1) = B(z, y_2) = -\delta \neq 0`$, so $`\varepsilon(x, y_1) = \varepsilon(x, z) = \varepsilon(x, y_2)`$. Taking $`y_2 = e`$ yields $`\varepsilon(x, y) = +1`$, i.e. $`\hat{L}_x(y) = \hat{R}_y(x)`$ for all $`x, y \in S_\delta`$.

3. **Unital Hurwitz composition algebra**:
   Since $`|S_\delta| > 3^{2m-2} + 3^{m-1}`$, $`S_\delta`$ spans $`V`$; pick a basis $`b_1, \dots, b_{2m} \in S_\delta`$ and set $`(\sum \alpha_i b_i) \star v := \sum \alpha_i \hat{L}_{b_i}(v)`$. Then $`u \star y = \hat{R}_y(u)`$ ($`\forall u \in V, y \in S_\delta`$) as both sides agree on $`b_1, \dots, b_{2m}`$, whence $`x \star v = \hat{L}_x(v)`$ ($`\forall x \in S_\delta, v \in V`$) as both sides agree on the spanning set $`S_\delta`$ ($`e \star v = v \star e = v`$). Putting $`\widetilde{Q}(v) := \delta^{-1}Q(v)`$, for each $`v \in V`$ the $`\mathbb{F}_3`$-quadratic form $`F_v(u) := \widetilde{Q}(u \star v) - \widetilde{Q}(u)\widetilde{Q}(v)`$ vanishes on $`S_\delta`$. By Hurwitz's Theorem (Springer–Veldkamp 2000, Theorem 1.6.2 & Corollary 1.7.5), $`\dim_{\mathbb{F}_3} V = 2m \in \{1, 2, 4, 8\}`$ with $`2m \ge 6`$ forces **$`2m = 8`$**, $`\varepsilon = +`$, and $`(V, \star, \widetilde{Q}) \cong (\mathbb{O}(\mathbb{F}_3), \cdot, N)`$, so $`Q_{\mathrm{loop}} \cong M(3)`$ (Moufang). Finally, BvM Theorem 11.3.2(ix) and §10.78 identify the $`\Omega_7(3)`$ action on $`G_2(3)`$-cosets (`deg 1080`) with this same orbital graph, so its permutation image $`\widetilde{\Omega}_7(3)`$ lies in the full graph group $`\mathop{\mathrm{PO}}\nolimits_8^+(3)`$, so any loop with $`\mathop{\mathrm{Mlt}}\nolimits(Q_{\mathrm{loop}}) \le \widetilde{\Omega}_7(3)`$ would satisfy $`Q_{\mathrm{loop}} \cong M(3)`$, contradicting $`|\mathop{\mathrm{Mlt}}\nolimits(M(3))| = |\mathop{\mathrm{P\Omega}}\nolimits_8^+(3)| = 1080 \cdot |\Omega_7(3)| > |\Omega_7(3)|`$. $`\square`$

### 3. `CFSG`-Free Elimination of Half-Spin, Odd-Orthogonal, Unitary $`\mathrm{NU}_m(2)`$, Symplectic Hyperplane, and $`G_2(q)`$ Families

The $`\mathbb{F}_q`$-subspace $`L := \{v_2 \in V : B(v_2, v_1) = B(v_2, \hat{a}(v_1)) = B(\hat{a}(v_2), v_1) = 0\}`$ contains $`v_1`$ and has $`\dim_{\mathbb{F}_q} L \ge 2w - 3 \ge 7`$, so a complement $`L'`$ of $`\mathbb{F}_q v_1`$ inside $`L`$ has $`\dim_{\mathbb{F}_q} L' \ge 6 \ge 5`$. Hence there is $`0 \neq v_2 \in L'`$ with $`Q(v_2) = B(v_2, \hat{a}(v_2)) = 0`$. Then $`W := \mathop{\mathrm{Span}}\nolimits_{\mathbb{F}_q}(v_1, v_2, \hat{a}(v_1), \hat{a}(v_2))`$ is totally singular of dimension $`r \le 4 \le w - 1`$, so $`W^\perp / W`$ ($`\dim = 2(w - r) \ge 2`$, split) extends $`W`$ to $`Y \in \mathcal{M}_+`$. Linear independence of $`v_1, v_2`$ gives $`\mathop{\mathrm{Span}}\nolimits_{\mathbb{F}_q}(\hat{a}(v_1), \hat{a}(v_2)) \le Y \cap \hat{a}(Y)`$ of dimension $`2`$, and parity $`\dim(Y \cap a(Y)) \equiv w \equiv 1 \pmod 2`$ (same half-spin class iff intersection has even codimension: Schillewaert–Van Maldeghem, *On the varieties of the second row of the split Freudenthal–Tits Magic Square*, Ann.    - If $`\sigma \neq \mathrm{id}`$ ($`f \ge 2, q \ge 9, 1 \le s \le f - 1`$): for singular $`0 \neq u \in V`$ ($`2m + 1 \ge 5`$) and $`w \in u^\perp`$ with $`Q(w) = \delta_\varepsilon`$, expanding $`B(t u + w, t^{p^s}\hat{a}(u) + \hat{a}(w)) = 0`$ ($`\forall t \in \mathbb{F}_q`$, distinct exponents $`0 < 1 < p^s < 1 + p^s < q`$) gives $`B(w, \hat{a}(u)) = 0`$. The $`\delta_\varepsilon`$-level spans $`u^\perp`$: write $`u^\perp=\langle u\rangle\oplus W`$, where $`W`$ has a Witt decomposition into hyperbolic pairs $`e_i,f_i`$ and an anisotropic vector $`h`$ of norm $`d`$. The vectors $`e_i+(\delta_\varepsilon-dt^2)f_i+th`$ have norm $`\delta_\varepsilon`$; their values at $`t=0,\pm1`$ span $`e_i,f_i,h`$, and adding multiples of $`u`$ also spans $`u`$. Hence $`\hat{a}(u) \in (u^\perp)^\perp = \mathbb{F}_q u`$ for every singular $`u`$, contradicting $`1 \le p^s - 1 < q - 1`$ on orthogonal singular pairs ($`m \ge 2`$).
   - If $`\sigma = \mathrm{id}`$ ($`M \in O_{2m+1}(q)`$): $`F(y) := B(y, M y) = \frac{1}{2}B(y, (M + M^*)y)`$ vanishes on $`Q(y) = \delta_\varepsilon`$. This also eliminates $`G_2(3)`$ (`deg 351` inside $`\mathrm{NO}_7^-(3)`$ and `deg 378` inside $`\mathrm{NO}_7^+(3)`$).

### General $`\Delta_0`$ classification and fixed-point argument

This expansion covers $`r\ge2`$, $`q=2^f`$ with $`f\ge2`$, and either Arf type. Its scoped independent review is recorded at the end of this proof. Let $`Q_e`$ be a refinement of the alternating form $`B`$ having the type of the orbit under consideration, so the centered orbit is $`\Omega=\{v:\widetilde Q(v)=0\}`$ with $`\widetilde Q=\mathop{\mathrm{Tr}}\nolimitsQ_e`$. As in the centered action below, use $`g(v)=M(v^\sigma)+c`$ and $`J(v)=I(v,g(v))`$. The identification of this relation and the affine action is an input, not a consequence of the binary calculation.

First extend the binary zero-set lemma below to plus type. Let $`q_2`$ be a nondegenerate plus-type quadratic form on a binary space of dimension $`2m\ge4`$, and let $`D`$ be a polynomial of degree at most two vanishing on its zeros. Choose a hyperbolic basis $`e_i,f_i`$ ($`1\le i\le m`$), and let $`b_D`$ be the polar form. We have $`D(0)=D(e_i)=D(f_i)=0`$. Sums of distinct basis vectors are singular except $`e_i+f_i`$, so all off-pair polar values vanish. Write $`d_i=b_D(e_i,f_i)`$. The singular vector $`e_i+f_i+e_j+f_j`$ forces $`d_i=d_j`$ for every $`i\ne j`$. Therefore $`D=\lambda q_2`$ by comparison on the basis and all polar pairs. The minus-type proof is given in the [bounded $`q=4`$ subsection](#q4-zero-set-lemma-and-proposed-delta_0-classification); here $`\dim_{\mathbb F_2}V=2rf\ge8`$, so its dimension hypothesis holds. Componentwise, either type gives $`J=\gamma\widetilde Q`$ on $`V`$ whenever $`J`$ vanishes on $`\Omega`$.

Suppose $`g`$ is $`\Delta_0`$-UOD on $`\Omega`$, so $`J=0`$ there and $`g`$ has no fixed point in $`\Omega`$. Polarization gives

```math
B(x,y)+B(x,y)^\sigma+w(x,y)+w(x,y)^2=\gamma\mathop{\mathrm{Tr}}\nolimitsB(x,y),\quad
 w=B(x,M(y^\sigma))+B(y,M(x^\sigma)). \tag{G1}
```

If $`f\ge3`$ and $`\sigma:z\mapsto z^{2^j}`$ is nontrivial, take $`B(x,y)=0`$ and write $`P=B(x,M(y^\sigma))`$, $`T=B(y,M(x^\sigma))`$. Scaling $`x`$ by $`a`$ gives

```math
aP+a^{2^j}T+a^2P^2+a^{2^{j+1}}T^2=0\quad(a\in\mathbb F_q).
```

Reduce $`a^q`$ to $`a`$. For $`1<j<f-1`$ the exponents are distinct; for $`j=1`$ the coefficients of $`a`$ and $`a^4`$ give $`P=T=0`$; for $`j=f-1`$ the coefficients of $`a^2`$ and $`a^{2^{f-1}}`$ do so. These include $`f=3`$. The reduced polynomial has degree below $`q`$. Thus $`M(y^\sigma)\in\langle y\rangle`$ for every $`y`$ by nondegeneracy of $`B`$. Applying this to independent $`u,v`$, $`u+v`$ and $`u+av`$ forces $`a^\sigma=a`$ for every $`a`$, contradiction.

For $`\sigma=1`$, (G1) on $`B(x,y)=0`$, followed by scaling $`x`$, gives $`w=0`$ there. For fixed $`x\ne0`$, $`w(x,-)`$ is therefore a multiple of $`B(x,-)`$; bilinearity and nondegeneracy make that multiple independent of $`x`$, so $`w=\mu B`$. Comparison of polynomial coefficients in $`\mu z+\mu^2z^2=\gamma\mathop{\mathrm{Tr}}\nolimitsz`$ ($`z\in\mathbb F_q`$) forces $`\gamma=\mu=0`$ for $`f\ge3`$. Thus $`M^2=1`$ and $`J=0`$ on all of $`V`$.

For $`q=4`$, the coefficient calculation and the two fixed-point alternatives in the [local $`\Delta_0`$ proof](#q4-zero-set-lemma-and-proposed-delta_0-classification) apply in either type and every $`r\ge2`$: they use the corresponding zero-set lemma, nondegeneracy of $`B`$, the action compatibility, and additive Hilbert 90, with no dimension or Arf-sign restriction beyond those just stated. They likewise give $`\sigma=1`$, $`M^2=1`$ and $`J=0`$. This generalization is not part of the older bounded review recorded below.

In either case set $`N=M+1`$. The affine square of $`g`$ is a pure translation, and no nonzero pure translation preserves the two zero/nonzero classes of the nondegenerate binary form $`\widetilde Q`$: otherwise its difference would be the nonconstant linear function $`\mathop{\mathrm{Tr}}\nolimitsB(v,d)`$ plus a constant. Thus $`Mc=c`$. The linear action compatibility, restricted to $`\ker N`$, gives $`B(v,c)=0`$ for all $`v\in\ker N`$. Since $`M`$ is symplectic and involutory, $`(\ker N)^\perp=\mathop{\mathrm{im}}\nolimitsN`$; hence $`c=Nz_0`$ for some $`z_0`$. Using $`Mc=c`$ in the expansion of $`J=0`$ yields $`Q_e(c)+B(v,Mv)+B(v,Mv)^2=0`$. Evaluation at $`0`$ and scaling $`v`$ give $`Q_e(c)=0`$ and $`B(v,Nv)=0`$ for all $`v`$.

The bilinear form $`(x,y)\mapsto B(x,Ny)`$ is alternating, since it has zero diagonal and is symmetric by symplecticity and $`M^2=1`$. Its rank is $`\mathop{\mathrm{rank}}\nolimitsN`$, hence this rank is even. Also $`N^2=0`$, so $`\mathop{\mathrm{im}}\nolimitsN\subseteq\ker N`$ and $`\mathop{\mathrm{rank}}\nolimitsN\le r`$. The fixed set of $`g`$ on $`V`$ is the affine space $`z_0+\ker N`$.

If $`\mathop{\mathrm{rank}}\nolimitsN<r`$, then $`\dim_{\mathbb F_q}\ker N>r`$. Its binary trace-polar form $`\mathop{\mathrm{Tr}}\nolimitsB`$ cannot vanish on $`\ker N`$: a totally isotropic binary subspace for this nondegenerate symplectic form has dimension at most $`rf`$, whereas $`\ker N`$ has larger binary dimension. Therefore $`\widetilde Q`$ cannot be constant on $`z_0+\ker N`$, so that fixed coset meets both binary level sets, including $`\Omega`$. In particular, if $`r`$ is odd then the even rank of $`N`$ is strictly below $`r`$, giving the desired contradiction in either Arf type.

It remains to consider $`\mathop{\mathrm{rank}}\nolimitsN=r`$, possible only for even $`r`$. Put $`L=\ker N=\mathop{\mathrm{im}}\nolimitsN`$, a Lagrangian. For $`u\in L`$, choose $`v`$ with $`Nv=u`$. The linear compatibility gives $`Q_e(u)+B(v,u)=B(Mv,c)^2`$. Here $`B(v,u)=B(v,Nv)=0`$ and $`B(Mv,c)=B(v,c)=B(Nv,z_0)=B(u,z_0)`$, since $`c=Nz_0`$ and $`N`$ is self-adjoint. Thus $`Q_e(u)=B(u,z_0)^2`$. Hence $`\widetilde Q`$ is constant on $`z_0+L`$. Choose a symplectic basis $`e_i,f_i`$ with $`e_i`$ a basis of $`L`$, and write $`z_0=\sum_i(\alpha_i e_i+\beta_i f_i)`$. Then $`Q_e(e_i)=\beta_i^2`$, and

```math
\mathop{\mathrm{Tr}}\nolimitsQ_e(z_0)
 =\mathop{\mathrm{Tr}}\nolimits\sum_i\bigl((\alpha_i\beta_i)^2+\alpha_i\beta_i+\beta_i^2Q_e(f_i)\bigr)
 =\mathop{\mathrm{Tr}}\nolimits\sum_iQ_e(e_i)Q_e(f_i)
 =\mathop{\mathrm{Arf}}\nolimits(Q_e).
```

Here $`\mathop{\mathrm{Arf}}\nolimits(Q_e)`$ denotes the absolute-trace Arf invariant. Thus the fixed coset lies in $`\Omega`$ when the chosen refinement is plus type, giving a contradiction. For minus type and even $`r`$, this last calculation gives no contradiction; that case needs the separate arguments below.

### $`q=4`$ zero-set lemma and proposed $`\Delta_0`$ classification

These prerequisites have the bounded independent review recorded below. Let $`q`$ be a nondegenerate minus-type quadratic form on a $`2m`$-dimensional $`\mathbb F_2`$-space, $`m\ge3`$. If an $`\mathbb F_2`$-valued polynomial $`D`$ of degree at most two vanishes at every zero of $`q`$, then $`D=\gamma q`$ for some $`\gamma\in\mathbb F_2`$.

To see this, take a Witt basis $`e_i,f_i`$ ($`1\le i\le m-1`$) and anisotropic vectors $`a,b`$ with $`q(a)=q(b)=b_q(a,b)=1`$. Write $`b_D`$ for the polar form of $`D`$. Since $`0,e_i,f_i`$ are singular, $`D`$ vanishes on them. Singular sums of distinct hyperbolic basis vectors give all their cross-polar values except $`d_i=b_D(e_i,f_i)`$. For $`j\ne i`$, the vectors $`a+e_i+f_i`$ and its sums with $`e_j`$ and $`f_j`$ are singular, giving $`b_D(a,e_j)=b_D(a,f_j)=0`$; the same holds for $`b`$. As at least two hyperbolic planes exist, these vanish for every $`j`$. Evaluating $`D(a+e_i+f_i)=D(b+e_i+f_i)=0`$ yields $`D(a)=D(b)=d_i`$ for all $`i`$. Finally $`a+b+e_i+f_i`$ is singular, so $`b_D(a,b)=d_i`$. Thus $`D`$ and $`d_iq`$ agree on the basis and all polar pairs and are identical. Applying this componentwise to an $`\mathbb F_4`$-valued polynomial gives $`D=\gamma q`$ with $`\gamma\in\mathbb F_4`$.

For the proposed $`q=4`$ classification, use the centered affine action and notation of the next subsection, with $`\widetilde Q=\mathop{\mathrm{Tr}}\nolimitsQ_e`$ and $`\Omega_-=\{\widetilde Q=0\}`$. A $`\Delta_0`$-UOD element $`g(v)=M(v^\sigma)+c`$ has $`J(v)=0`$ on $`\Omega_-`$, so the lemma gives $`J=\gamma\widetilde Q`$. Since $`g`$ preserves both Arf classes, $`\mathop{\mathrm{Tr}}\nolimitsJ=0`$ and $`\gamma\in\mathbb F_2`$. Polarizing gives equation (1) below. Its coefficient separation is as follows: in the semilinear case let $`A=B(x,M(y^2))`$, $`C=B(y,M(x^2))`$ and $`d=B(x,y)`$. Substitution of $`ax,by`$ in (1) yields
$$ab^2 A+ba^2 C+a^2b A^2+b^2a C^2=(\gamma+1)(ab d+a^2b^2d^2).$$
The four functions $`ab,ab^2,a^2b,a^2b^2`$ are linearly independent as functions of $`(a,b)\in\mathbb F_4^2`$. Thus $`\gamma=1`$ and $`A=C^2`$, implying $`T^2=I`$ for $`T=M\sigma`$. The induced affine action is faithful on its linear part, so $`g^2=I`$ and $`Tc=c`$. Additive Hilbert 90 for the involutory Frobenius-semilinear $`T`$ gives $`\ker(T+I)=\mathop{\mathrm{im}}\nolimits(T+I)`$, hence $`g`$ has a fixed point $`v`$. But $`J(v)=0`$ and $`J=\widetilde Q`$ put $`v\in\Omega_-`$, contradicting $`\Delta_0`$-UOD.

In the linear case, the polarization gives $`M+M^{-1}=\gamma I`$. If $`\gamma=1`$, then $`M^2+M+I=0`$, so $`I+M`$ is invertible and $`g`$ has a fixed point $`v`$; $`J=\widetilde Q`$ again gives $`v\in\Omega_-`$, a contradiction. If $`\gamma=0`$, then $`M^2=I`$ and $`J=0`$ identically. Put $`N=M+I`$. The compatibility $`Q_e(Mv)+Q_e(v)=B(Mv,c)^2`$ on $`\ker N`$ gives $`c\in(\ker N)^\perp=\mathop{\mathrm{im}}\nolimitsN`$. Since $`N^2=0`$ and $`M`$ is symplectic, $`B(Nv,c)=0`$ for all $`v`$. Expanding $`J(av)=0`$ for all $`a\in\mathbb F_4`$ then gives $`B(v,Mv)=0`$, i.e. $`B(v,Nv)=0`$. In particular every such $`\Delta_0`$ element has the form required as hypothesis (A) of the conditional all-loops obstruction. The action identification and these deductions have the review recorded below.

    N_x y = T(x^tau)+x.

### $`q=8`$ character-sum sublemma

The following sublemma was independently accepted at source `recorded source version`, with the review scoped to this sublemma. Its application to the full action below requires separate review.

For the following sublemma only, let $`V`$ be a nondegenerate symplectic space of dimension $`n=4s\ge 8`$ over $`\mathbb F_8`$, and let $`Q_e`$ be a quadratic refinement of $`B`$ with absolute-trace Arf invariant 1. Put $`J(y)=Q_e(y)+Q_e(g(y))+B(y,g(y))+B(y,g(y))^2`$. Then some $`y`$ has $`\mathop{\mathrm{Tr}}\nolimits Q_e(y)=0`$ and $`J(y)=0`$.

Indeed, preservation of the indicated set by the bijection $`g`$ implies $`\mathop{\mathrm{Tr}}\nolimitsQ_e(g(y))=\mathop{\mathrm{Tr}}\nolimitsQ_e(y)`$ for all $`y`$, so $`\mathop{\mathrm{Tr}}\nolimitsJ(y)=0`$. Suppose the conclusion fails. Set $`N=3n`$, $`\widetilde Q=\mathop{\mathrm{Tr}}\nolimitsQ_e`$, and $`S(h)=\sum_{y\in V}(-1)^{h(y)}`$. For the three nontrivial additive characters of the trace-zero plane, choose representatives $`\lambda\in\mathbb F_8/\mathbb F_2`$ other than $`\mathbb F_2`$, and let $`h_{\lambda,\alpha}=\mathop{\mathrm{Tr}}\nolimits(\lambda J)+\alpha\widetilde Q`$, $`\alpha\in\mathbb F_2`$. Character orthogonality yields

```math
0=2^N+S(\widetilde Q)+\sum_\lambda\bigl(S(h_{\lambda,0})+S(h_{\lambda,1})\bigr).
```

Each $`h_{\lambda,\alpha}`$ is a Boolean quadratic polynomial, possibly with linear and constant terms. Its polar rank is even, and its sum has absolute value at most $`2^{N-\mathop{\mathrm{rank}}\nolimits(b_{\lambda,\alpha})/2}`$. Since $`b_{\lambda,0}+b_{\lambda,1}=\mathop{\mathrm{Tr}}\nolimitsB`$ is nondegenerate, the two ranks sum to at least $`N`$. If every rank were at least 4, the absolute value of each parenthesized sum would be at most $`2^N(1/4+2^{-(N/2-2)})`$. Meanwhile $`|S(\widetilde Q)|=2^{N/2}`$, and $`1-2^{-N/2}>3(1/4+2^{-(N/2-2)})`$ for $`N\ge24`$, a contradiction. Thus one polar form has rank at most 2.

Direct polarization, using $`B(Mx^\sigma,My^\sigma)=B(x,y)^\sigma`$ and $`\mathop{\mathrm{Tr}}\nolimits(z^2)=\mathop{\mathrm{Tr}}\nolimits(z)`$, gives

```math
b_{\lambda,\alpha}(x,y)=\mathop{\mathrm{Tr}}\nolimits\!\left(uB(x,y)+t\bigl(B(x,M(y^\sigma))+B(y,M(x^\sigma))\bigr)\right),\quad
u=\lambda+\lambda^{\sigma^{-1}}+\alpha,\quad t=\lambda+\lambda^4\ne0.
```

Here $`\sigma^{-1}`$ denotes the inverse field automorphism, and the nonzero assertion follows because the fixed field of $`z\mapsto z^4`$ in $`\mathbb F_8`$ is $`\mathbb F_2`$.

Let $`R`$ be the radical of this form, and let $`1,\omega,\omega^2`$ be an $`\mathbb F_2`$-basis of $`\mathbb F_8`$. Then $`U=R\cap\omega R\cap\omega^2R=\{x: ax\in R\text{ for all }a\in\mathbb F_8\}`$ is an $`\mathbb F_8`$-subspace. Its $`\mathbb F_2`$-codimension is at most 6, hence $`\dim_{\mathbb F_8}U\ge n-2`$. For $`x,y\in U`$, both $`ax`$ and $`by`$ lie in $`R`$ for every $`a,b\in\mathbb F_8`$. Using nondegeneracy of the trace pairing in $`a`$ gives, for every $`b\in\mathbb F_8`$,

```math
u b B(x,y)+t b^\sigma B(x,M(y^\sigma))+
\bigl(t b B(y,M(x^\sigma))\bigr)^{\sigma^{-1}}=0.
```

The exponents $`1,\sigma,\sigma^{-1}`$ are $`1,2,4`$ in some order. The resulting polynomial has degree at most 4 and vanishes at all eight field elements, so its coefficients vanish. In particular $`B(x,M(y^\sigma))=0`$ for all $`x,y\in U`$. Hence $`M(U^\sigma)\subseteq U^\perp`$, impossible because $`\dim M(U^\sigma)=\dim U\ge n-2>2\ge\dim U^\perp`$. This proves the sublemma.


### $`q=8`$ proposed action and orbital application

The following application has the scoped independent review recorded at the end of this proof. It does not establish the aggregate C0016 claim.

Let V have dimension n=4s≥8 over F8, with nondegenerate alternating B. Fix a quadratic refinement Q=Qe of minus type, so Tr Arf(Q)=1. The refinements of B are Q_y(z)=Q(z)+B(y,z)^2, uniquely indexed by y∈V. Their Arf invariants differ by Q(y) modulo the trace-zero subgroup, so the minus refinements are exactly Ω={y: Tr Q(y)=0}. A semilinear symplectic transformation T=Mσ, with M symplectic and σ∈Gal(F8/F2), acts by Q_y ↦ (Q_y∘T^{-1})^σ; it therefore induces y↦M(y^σ)+c for a uniquely determined c, and preserves Ω. (Choose a symplectic basis and apply σ to coordinates; M is the resulting linear part.)

For any x,y define I(x,y)=Q(x)+Q(y)+B(x,y)+B(x,y)^2. It is Q_x(x+y). Consequently it is intrinsic: after applying T, I(gx,gy)=I(x,y)^σ. At x=0, I(0,y)=Q(y). By Witt's extension theorem O(Q) is transitive on nonzero vectors with any fixed Q-value. Since Q can be written with F2 coefficients (a sum of hyperbolic planes and one anisotropic plane X²+XY+Y²), coordinate Frobenius lies in its semilinear stabilizer and cycles the three nonzero trace-zero values in F8. Thus the full semilinear action has diagonal and exactly two nontrivial orbitals: Δ0 corresponds to I=0 with x≠y, and Δ1 to I≠0. The F8-linear symplectic action has five point-stabilizer orbits: 0, the nonzero singular vectors, and one orbit for each of the three nonzero trace-zero Q-values.

The reviewed q=8 sublemma rules out semilinear Δ1-UOD elements: such an element preserves Ω and would have I(y,gy)≠0 for all y∈Ω, contrary to the sublemma. We now independently exclude semilinear Δ0-UOD elements. Suppose instead J(y)=I(y,gy)=0 for all y∈Ω, where g(y)=M(y^σ)+c and σ is squaring or fourth power. Choose independent Q-singular, B-orthogonal vectors x,y. Then ax+by∈Ω for all a,b∈F8, since Q(ax+by)=0. Polarizing J on ax,by, using symplecticity of M and B(x,y)=0, gives

    w(a,b)+w(a,b)^2=0,
    w(a,b)=a b^σ B(x,M(y^σ))+b a^σ B(y,M(x^σ)).

Setting b=1, and comparing coefficients of the polynomial in a of degree at most 4 after reducing a^8 to a, shows both displayed B-values vanish: if σ=2 its coefficients at a,a²,a⁴ are P, Q'+P², Q'²; if σ=4 they are P+Q'², P², Q', where P=B(x,M(y^σ)) and Q'=B(y,M(x^σ)). The polynomial vanishes on all eight elements, hence is zero.

For fixed nonzero singular y, the singular vectors in y⊥ span y⊥: the quotient y⊥/⟨y⟩ is a nondegenerate minus quadratic space of dimension n−2≥6 and Witt index at least 2; its singular vectors span it, and singular representatives lift. (For the anisotropic plane, add a suitable vector from a hyperbolic plane to each anisotropic basis vector to obtain singular vectors.) Thus B(x,M(y^σ))=0 for all x∈y⊥, so M(y^σ)∈⟨y⟩. Every singular projective point is fixed by the semilinear map. In particular, for independent perpendicular singular x,y, their entire line consists of singular points. Writing M(x^σ)=αx and M(y^σ)=βy, the fixed points ⟨x+y⟩ and ⟨x+a y⟩ force α=β≠0 and a^σ=a for every a∈F8, contradiction. Therefore no element with nontrivial field automorphism is Δ0-UOD.

For a loop whose multiplication group lies in this semilinear action, every nonidentity left and right translation is UOD in one of these two orbitals (the orbital is determined by its displacement of the identity). Both exclusions force every translation into Sp(V), so the multiplication group is contained in Sp(V). Its point-stabilizer orbits refine the five Sp(V)-orbits, so its rank is at least five. This is only the q=8 application; it does not resolve the other portions of C0016.


### Even-unitary proposed argument

Let V be a nondegenerate Hermitian space of even F4-dimension m=2k≥6; H is linear in its first argument and H(y,y)∈F2. Suppose g is a semilinear unitary transformation, representing a projective permutation, and suppose H(y,gy)≠0 for every y with H(y,y)=1. We prove that g fixes a nonsingular projective point or there is y with H(y,y)=1 and H(y,gy)=0. Thus g cannot be Δ1-UOD under the convention that Δ1 is the nonorthogonality orbital. The identification of that orbital and the preceding character-sum count need separate geometric verification; the following starts with the stated algebraic condition.

Put J(y)=H(y,gy), Q(y)=H(y,y), and h_{λ,a}(y)=Tr(λJ(y))+aQ(y), λ∈F4*, a∈F2. Each is an F2-quadratic polynomial. Their polar ranks are even and for fixed λ their sum is at least 2m, since their sum is the nondegenerate polar of Q. Character orthogonality, combined with the assumption, gives 0=2^{2m}−S(Q)+∑λ(S(h_{λ,0})−S(h_{λ,1})). Since |S(Q)|=2^m, if all six ranks were at least 4 the right side would have magnitude at least 2^{2m}[1−2^{−m}−3(1/4+2^{−(m−2)})]>0 for m≥6. Thus one polar has rank ≤2.

If g is Frobenius-semilinear, then C(x,y)=H(x,gy) is F4-bilinear and β(x,y)=C(x,y)+C(y,x) is F4-bilinear alternating. The polar form is b(x,y)=Tr(λβ(x,y))+a Tr H(x,y). Let R=rad(b), and U=R∩ωR, where ω∈F4\F2. Then U is F4-linear and dim U≥m−2>m/2. For x,y∈U, b(cx,dy)=0 for all c,d∈F4. As c,d vary, independence of cd and cd² forces λβ(x,y)=0 and aH(x,y)=0. Nondegeneracy of H prevents U from being totally isotropic, so a=0. Now the F2-rank of Tr(λβ) is twice the F4-rank of β; the latter is even because β is alternating. The bound 2 therefore forces β=0.

The identity β=0 says H(x,gy)=H(y,gx), and the semilinear unitary identity yields g²=1. Standard Galois descent for an involutory Frobenius-semilinear map gives V=W⊗F2 F4, W=Fix(g). On W the Hermitian form is F2-valued. If some w∈W has H(w,w)=1, g fixes its nonsingular point. Otherwise H|W is alternating, and for y=u+ωv with u,v∈W, direct expansion gives H(y,gy)=0. Either outcome contradicts the assumed fixed-point-free nonorthogonality displacement.

If g=M is F4-linear, its polar form can be written b(x,y)=Tr H(x,Ay), where A=λ²M+λM^{-1}+aI, using adjoint M*=M^{-1}. Consequently rank_F4(A)≤1. Put K=λ²M, still unitary; then A=K+K^{-1}+aI. Multiplication by λ² changes neither projective fixed points nor zeros of H(y,My).

If a=1, ker(K²+K+I) has dimension at least m−1. The two eigenspaces for the distinct roots ω and ω² are orthogonal, because each is unitary of norm 1 and their eigenvalues differ. Their sum is a nondegenerate subspace; it therefore contains a norm-one vector, fixed projectively by M. (In fact its dimension ≥m−1 already exceeds the maximal totally isotropic dimension k.)

If a=0, N=K+I satisfies rank N²≤1. If N acts nontrivially on the line im N², this line is an eigenspace with eigenvalue θ≠0 for N. Since N² has rank one, V=im N²⊕ker N². The corresponding K-eigenvalue 1+θ∈F4* is different from 1, and unitary invariance makes these two primary components orthogonal. Thus im N² is nondegenerate and gives a nonsingular projectively fixed point. Otherwise N³=0.

If N²=0, unitarity gives N*=N, so im N is totally isotropic and ker N=(im N)⊥. If rank N<k, the nondegenerate Hermitian quotient ker N/im N has positive dimension and contains a norm-one vector, giving a fixed point. If rank N=k, the induced form H(x,Ny) on V/ker N is a nondegenerate Hermitian form, so there is x with H(x,Nx)=1. Choose u∈ker N with H(u,x)=ω; since ker N=im N is totally isotropic, y=x+u has H(y,y)=H(x,x)+1. By choosing the original x to have norm zero if necessary (adjust x by a suitable element of ker N, which does not change H(x,Nx)), arrange H(y,y)=1. Then H(y,Ny)=1 and H(y,Ky)=0, contradicting the assumption. Equivalently choose u directly so that Tr H(u,x)=1+H(x,x), possible because the pairing between ker N and V/ker N is nondegenerate and x∉ker N.

Finally suppose rank N²=1 and N³=0. Since K*=K^{-1}=I+N+N², (N²)*=N². The rank-one Hermitian form H(x,N²y) has a vector v with H(v,N²v)=1. The space W=⟨v,Nv,N²v⟩ is nondegenerate: its Gram matrix is antitriangular with nonzero antidiagonal, because H(N²v,N²v)=H(Nv,N²v)=0 and H(Nv,Nv)=H(v,N²v)=1. Its orthogonal complement is K-stable, has odd dimension m−3, and N²=0 there. In an odd-dimensional nondegenerate Hermitian space, im N is isotropic of dimension at most (m−3−1)/2, so ker N/im N has positive dimension and contains a norm-one vector. This gives a nonsingular projectively fixed point.
