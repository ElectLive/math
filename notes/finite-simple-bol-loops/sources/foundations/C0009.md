### 1. Weil-Restriction Isotropy and Infinite Rank $`\ge 3`$ Almost-Simple Exclusions

#### Lemma 1.1 (Weil-Restriction Isotropy via Chevalley–Warning)
Let $`q = p^f`$ ($`p`$ prime, $`f \ge 1`$) and $`V = \mathbb{F}_q^d`$. Viewing $`V \cong \mathbb{F}_p^{d f}`$ over $`\mathbb{F}_p`$, every field automorphism $`\sigma \in \mathop{\mathrm{Aut}}\nolimits(\mathbb{F}_q)`$ ($`z \mapsto z^{p^s}`$) is $`\mathbb{F}_p`$-linear, so any $`\sigma`$-sesquilinear or quadratic map $`V \to \mathbb{F}_q \cong \mathbb{F}_p^f`$ has $`f`$ coordinate polynomials over $`\mathbb{F}_p`$ of degree $`\le 2`$ vanishing at $`0`$. By the Chevalley–Warning Theorem over $`\mathbb{F}_p`$:
1. Every $`\sigma`$-sesquilinear form $`B : V \times V \to \mathbb{F}_q`$ on $`V = \mathbb{F}_q^d`$ with **$`d \ge 3`$** ($`2 f < 3 f \le d f`$) has a nonzero isotropic vector $`0 \neq v \in V`$ with $`B(v, v) = 0`$.
2. On a quadratic space $`(V, Q)`$ over $`\mathbb{F}_q`$ with **$`d \ge 5`$** ($`4 f < 5 f \le d f`$), for any $`\sigma`$-semilinear map $`\hat{a} : V \to V`$, there exists $`0 \neq v \in V`$ with $`Q(v) = 0`$ and $`B(v, \hat{a}(v)) = 0`$.
3. On a Hermitian space $`(V, H)`$ over $`\mathbb{F}_{q_0^2}`$ ($`q_0 = p^e`$, $`\dim_{\mathbb{F}_p} V = 2 e d`$) with **$`d \ge 4`$**, since $`H(v, v) \in \mathbb{F}_{q_0} \cong \mathbb{F}_p^e`$ ($`e`$ equations of degree $`2`$) and $`H(v, \hat{a}(v)) \in \mathbb{F}_{q_0^2} \cong \mathbb{F}_p^{2e}`$ ($`2e`$ equations of degree $`2`$), $`6 e < 8 e \le 2 e d`$ gives $`0 \neq v \in V`$ with $`H(v, v) = 0`$ and $`H(v, \hat{a}(v)) = 0`$. $`\square`$

#### Theorem 1.2 (Complete Analytical Exclusion of Infinite Rank $`\ge 3`$ Combinatorial and Subspace/Polar `AS` Families)
No loop $`(Q, *)`$ (left Bol or otherwise) has $`\mathop{\mathrm{Mlt}}\nolimits(Q) \le P`$ in any of the following primitive Almost-Simple (`AS`) actions of rank $`\ge 3`$:
1. **Johnson-orbital actions (any subgroup $`P \le \mathop{\mathrm{Aut}}\nolimits(A_m)`$ on $`\binom{[m]}{k}`$ whose orbitals coincide with the Johnson distance orbitals, all $`m \ge 5`$ and $`2 \le k < m/2`$, rank $`k + 1 \ge 3`$)**:
   *(This covers all $`A_m \le P \le \mathop{\mathrm{Aut}}\nolimits(A_m)`$ as well as proper subgroups sharing the Johnson orbitals; for $`m = 6, k = 2`$, $`\mathop{\mathrm{Stab}}\nolimits_{\mathop{\mathrm{Aut}}\nolimits(A_6)}(\binom{[6]}{2}) = S_6`$, while for $`m \neq 6`$, $`\mathop{\mathrm{Aut}}\nolimits(A_m) = S_m`$.)* Fix $`E = \{1, \dots, k\}`$ and $`X = \{k + 1, \dots, 2k\}`$ ($`E \cap X = \emptyset`$). Any $`a \in P \subseteq S_m`$ with $`a(E) = X`$ satisfies $`a(1) \notin E`$ ($`a(1) \neq 1`$); choosing $`Y \in \binom{[m]}{k}`$ containing $`\{1, a(1)\}`$ ($`k \ge 2`$) gives $`a(1) \in Y \cap a(Y) \neq \emptyset`$, violating `C0008` Lemma 2.1(1) on the disjointness orbital.
2. **Uniform set partitions ($`A_m \le P \le S_m`$ on $`\Pi_{a, b}`$, $`m = a b`$, all $`a \ge 2, b \ge 2`$ except the rank-$`2`$ cases $`(a, b) \in \{(2, 2), (3, 2)\}`$)**:
   - *Case $`b \ge 3, a \ge 2`$*: Fix $`E, X \in \Pi_{a, b}`$ sharing $`0`$ blocks ($`E \cap X = \emptyset`$, e.g. cyclic shift by $`+1 \bmod m`$). For any $`\pi \in S_m \setminus \{\mathrm{id}\}`$, let $`F`$ be the fixed points of $`\pi`$ and $`M = [m] \setminus F`$ the moved points (cycle lengths $`\ell_i \ge 2`$). Note $`Y \cap \pi(Y) \neq \emptyset`$ holds for some $`Y \in \Pi_{a, b}`$ whenever $`\exists C \in \binom{[m]}{a}`$ with $`\pi(C) = C`$ ($`C \in Y`$) or $`C \cap \pi(C) = \emptyset`$ ($`C, \pi(C) \in Y`$, valid since $`2a < a b`$). If $`|F| \ge a`$, pick $`C \subseteq F`$. If $`|F| \le a - 1`$ and $`b \ge 4`$, the maximum $`\pi`$-independent set has size $`\sum \lfloor \ell_i / 2 \rfloor \ge |M|/3 = (a b - |F|)/3 > a`$, giving $`C \cap \pi(C) = \emptyset`$. If $`b = 3`$, $`|F| \le a - 1`$, and $`\sum \lfloor \ell_i / 2 \rfloor \le a - 1`$: writing $`r_{\text{odd}}`$ for the number of moved odd cycles gives $`3a - |F| = |M| \le 2(a - 1) + r_{\text{odd}} \implies r_{\text{odd}} \ge a - |F| + 2`$, and $`\sum_{\text{even}} \ell_i + \sum_{\text{odd}}(\ell_i - 3) = |M| - 3 r_{\text{odd}} \le 2|F| - 6`$ (forcing $`|F| \ge 3`$). If $`2|F| \ge a`$ ($`a - |F| \le |F|`$), at most one cycle has $`\ell_1 > a`$ (else $`\sum \lfloor \ell_i / 2 \rfloor \ge a`$), with $`\ell_1 \le 2a - 1`$, leaving cycles of length $`\le a`$ summing to $`\ge a - |F| + 1`$; either one has $`\ell_i \in [a - |F|, a]`$ (pad with $`F`$), or all have $`\ell_i < a - |F| \le |F|`$ so greedy addition enters $`[a - |F|, a]`$. If $`2|F| \le a - 1`$, every cycle has $`\ell_i \le 2|F| - 3 < a`$, and at most one cycle has $`\ell_1 \ge |F| + 2`$ (as $`\ell_1 - 3 \ge |F| - 1`$ leaves $`< |F| - 1`$ in $`2|F| - 6`$); if $`\ell_1 \ge a - |F|`$ pad with $`F`$, else removing $`\ell_1`$ leaves cycles of length $`\le |F| + 1`$ summing to at least $`(3a-|F|)-(2|F|-3)=3a-3|F|+3>a`$ (using $`2|F|\le a-1`$), whose greedy sum enters $`[a - |F|, a]`$, giving $`\pi(C) = C`$.
   - *Case $`b = 2, a \ge 4`$ ($`m = 2a`$)*: Take the $`r = 1`$ orbital $`|U \cap V| \in \{1, a - 1\}`$. For $`\pi \in S_{2a} \setminus \{\mathrm{id}\}`$, $`f(U) := |U \cap \pi(U)|`$ changes by at most $`2`$ under single swaps $`U \mapsto (U \setminus \{u\}) \cup \{v\}`$. If $`|F| \ge 2a - 3`$ ($`1`$ transposition or $`1`$ $`3`$-cycle), $`\{1, 2\}`$ or $`\{1, 2, 3\} \subseteq U`$ gives $`f(U) = a \notin \{1, a - 1\}`$. If $`|F| \le 2a - 4`$, $`\mathbb{E}_U[f(U)] = \frac{|F|}{2} + (2a - |F|)\frac{a - 1}{2(2a - 1)} \in (1, a - 1)`$ strictly; for $`a \ge 5`$ the gap $`(a - 1) - 1 \ge 3 > 2`$ and swap-connectivity force some $`U`$ to satisfy $`1 < f(U) < a - 1`$, while for $`a = 4`$ exhaustive check over all $`21`$ non-identity cycle types of $`S_8`$ (`code/test_s1_obstructions.py`) likewise gives $`f(U) \notin \{1, 3\}`$.
3. **Linear Grassmannians ($`\mathop{\mathrm{PSL}}\nolimits_d(q) \le P \le \mathop{\mathrm{Aut}}\nolimits(\mathop{\mathrm{PSL}}\nolimits_d(q))`$ on $`\mathcal{G}_k(\mathbb{F}_q^d)`$, all $`d \ge 4`$, $`2 \le k \le d - 2`$, all $`q = p^f`$)**:
   Passing to $`V^*`$ if $`2k > d`$, assume $`2 \le k \le d/2`$, and fix $`E, X \in \mathcal{G}_k(V)`$ with $`E \cap X = \{0\}`$.
   - If $`a \in \mathop{\mathrm{P\Gamma L}}\nolimits_d(q)`$ ($`\sigma`$-semilinear lift $`\hat{a}`$) has $`a(E) = X`$, pick $`0 \neq v \in E`$; then $`\hat{a}(v) \in X \setminus \{0\}`$, so $`\dim\mathop{\mathrm{Span}}\nolimits_{\mathbb{F}_q}(v, \hat{a}(v)) = 2 \le k`$. Extending to $`Y \in \mathcal{G}_k(V)`$ gives $`0 \neq \hat{a}(v) \in Y \cap a(Y)`$.
   - If $`d = 2k`$ ($`k \ge 2`$) and $`a \in \mathop{\mathrm{Aut}}\nolimits(\mathop{\mathrm{PSL}}\nolimits_{2k}(q)) \setminus \mathop{\mathrm{P\Gamma L}}\nolimits_{2k}(q)`$ is a correlation $`a(Y) = Y^{\perp_B}`$ for a nondegenerate $`\sigma`$-sesquilinear form $`B`$ on $`\mathbb{F}_q^{2k}`$, Lemma 1.1(1) ($`2k \ge 4 \ge 3`$) gives $`0 \neq v \in V`$ with $`B(v, v) = 0`$. The $`\mathbb{F}_q`$-hyperplane $`H_v = \ker(y \mapsto \sigma^{-1}(B(y, v)))`$ has $`\dim_{\mathbb{F}_q} H_v = 2k - 1 \ge k`$ and contains $`v`$; any $`Y \in \mathcal{G}_k(V)`$ with $`v \in Y \le H_v`$ satisfies $`0 \neq v \in Y \cap Y^{\perp_B} = Y \cap a(Y)`$.
4. **Classical polar spaces on isotropic/singular points and totally isotropic/singular $`k`$-subspaces (all $`q`$)**:
   - *Symplectic*: $`\mathop{\mathrm{PSp}}\nolimits_{2m}(q) \le P \le \mathop{\mathrm{P\Gamma Sp}}\nolimits_{2m}(q)`$ ($`m \ge 2`$, all $`q = p^f`$) on $`\mathbb{P}(\mathbb{F}_q^{2m})`$ (rank $`3`$: on the non-perp orbital $`B(e, x) \neq 0`$, for any $`\sigma`$-semilinear similarity $`\hat{a}`$ of $`V = \mathbb{F}_q^{2m}`$, Lemma 1.1(1) gives $`0 \neq v \in V`$ on the ambient space $`V`$ with $`B(v, \hat{a}(v)) = 0`$), and on totally isotropic $`k`$-subspaces ($`2 \le k \le m`$: on the disjoint orbital $`E \cap X = \{0\}`$, choose $`0 \neq v \in V`$ on the ambient space $`V`$ via Lemma 1.1(1) with $`B(v, \hat{a}(v)) = 0`$; since $`B(v, v) = 0`$ is automatic, $`W_0 = \mathop{\mathrm{Span}}\nolimits_{\mathbb{F}_q}(v, \hat{a}(v))`$ is totally isotropic of dimension $`1`$ or $`2 \le k`$ and Witt-extends to $`Y`$, giving $`0 \neq \hat{a}(v) \in Y \cap a(Y)`$). *(Also directly excludes $`\mathop{\mathrm{Sp}}\nolimits_{2m}(2)`$ of rank $`3`$ on $`\mathbb{F}_2^{2m} \setminus \{0\}`$ for all $`m \ge 2`$.)*
   For the unitary and orthogonal **point** actions, use the invariant nonperpendicular relation, rather than disjointness. If a loop exists, let its identity be the singular or isotropic point $`E=[e]`$ and choose a point $`X=[x]`$ with $`H(e,x)\ne0`$ or $`B(e,x)\ne0`$; complete $`e`$ to a hyperbolic pair to obtain $`x`$. Its left translation $`a=L_X`$ takes $`E`$ to $`X`$ and UOD forces every pair $`([v],a[v])`$ to be nonperpendicular.    - *Unitary*: $`\mathop{\mathrm{PSU}}\nolimits_d(q_0) \le P \le \mathop{\mathrm{P\Gamma U}}\nolimits_d(q_0) = \mathop{\mathrm{Aut}}\nolimits(\mathop{\mathrm{PSU}}\nolimits_d(q_0))`$ ($`d \ge 4`$, all $`q_0 = p^e`$) on isotropic points of $`\mathbb{P}(V)`$ ($`V = \mathbb{F}_{q_0^2}^d`$, rank $`3`$) and on totally isotropic $`k`$-subspaces ($`2 \le k \le \lfloor d/2 \rfloor`$, including rank-$`3`$ isotropic lines at $`d = 4, k = 2`$): for $`k \ge 2`$, on $`E \cap X = \{0\}`$, Lemma 1.1(3) gives $`0 \neq v \in V`$ on the ambient space $`V`$ with $`H(v, v) = H(v, \hat{a}(v)) = 0`$, so $`W_0 = \mathop{\mathrm{Span}}\nolimits_{\mathbb{F}_{q_0^2}}(v, \hat{a}(v))`$ is totally isotropic of dimension $`\le 2 \le k`$ and Witt-extends to $`Y`$ with $`0 \neq \hat{a}(v) \in Y \cap a(Y)`$.
   - *Orthogonal singular*: $`\mathop{\mathrm{P\Omega}}\nolimits_d^\varepsilon(q) \le P \le \mathop{\mathrm{P\Gamma O}}\nolimits_d^\varepsilon(q)`$ ($`d \ge 5`$, all $`q = p^f`$, Witt index $`w \ge 2`$) on singular points of $`\mathbb{P}(V)`$ ($`V = \mathbb{F}_q^d`$, rank $`3`$; for $`(d, \varepsilon) = (8, +)`$, triality permutes the singular quadric with the two half-spin varieties so its stabilizer in $`\mathop{\mathrm{Aut}}\nolimits(\mathop{\mathrm{P\Omega}}\nolimits_8^+(q))`$ is $`\mathop{\mathrm{P\Gamma O}}\nolimits_8^+(q)`$) and on totally singular $`k`$-subspaces for $`2 \le k \le w`$ in types $`O_{2w+1}(q), O_{2w+2}^-(q)`$ and **$`2 \le k \le w - 1`$** in type $`O_{2w}^+(q)`$ ($`w \ge 3`$), as well as each half-spin variety $`\mathcal{M}_\pm`$ of $`O_{2w}^+(q)`$ ($`P \le \mathop{\mathrm{P\Gamma SO}}\nolimits_{2w}^+(q)`$) for **even** $`w \ge 4`$: for the stated subspace actions, on $`E \cap X = \{0\}`$, Lemma 1.1(2) gives $`0 \neq v \in V`$ on the ambient space $`V`$ with $`Q(v) = B(v, \hat{a}(v)) = 0`$, so $`W_0 = \mathop{\mathrm{Span}}\nolimits_{\mathbb{F}_q}(v, \hat{a}(v))`$ is totally singular of dimension $`\le 2`$ and Witt-extends to $`Y`$ (including $`Y \in \mathcal{M}_+`$ when $`w \ge 4`$ is even, since $`\dim W_0 \le 2 \le w - 1`$) with $`0 \neq \hat{a}(v) \in Y \cap a(Y)`$. $`\square`$

### 2. Paige's $`M(q)`$ Litmus Test and the Hurwitz–Paige Moufang Collapse Theorem Over $`\mathbb{F}_2`$

#### Theorem 2.1 (Paige $`M(q)`$ Rank $`\ge 3`$ Mechanism and Hurwitz–Paige Moufang Collapse for $`O_{2m}^\varepsilon(2)`$)
1. **Why Paige's simple Moufang loops $`M(q)`$ satisfy Uniform Orbital Displacement at rank $`\ge 3`$**:
   In Zorn's split octonion algebra $`\mathbb{O}(\mathbb{F}_q)`$ with norm $`N`$ of Witt index $`4`$ and polar form $`B(X, Y) = N(X + Y) - N(X) - N(Y) = \mathop{\mathrm{Tr}}\nolimits(X \bar{Y})`$, alternativity $`(X Y)\bar{Y} = X(Y \bar{Y}) = N(Y) X`$ forces
   $$B(Y, X Y) = \mathop{\mathrm{Tr}}\nolimits((X Y)\bar{Y}) = N(Y)\mathop{\mathrm{Tr}}\nolimits(X) = B(1, X) \qquad \forall X, Y \in \mathbb{O}(\mathbb{F}_q) \text{ with } N(X) = N(Y) = 1.$$
   Thus $`M(q) = \{X : N(X) = 1\}/\{\pm 1\}`$ satisfies `C0008` Lemma 2.1(1) inside $`\mathop{\mathrm{Mlt}}\nolimits(M(q)) = \mathop{\mathrm{P\Omega}}\nolimits_8^+(q)`$ (Nagy–Vojtěchovský, *Octonions, simple Moufang loops and triality*, Quasigroups Related Systems **10** (2003), Corollary 4.7, p. 79, [journal PDF](https://www.math.md/files/qrs/v10-n1/v10-n1-%28pp65-94%29.pdf); `arXiv:math/0701707v1`) across **all** orbitals simultaneously, with $`\mathop{\mathrm{rank}}\nolimits(\mathop{\mathrm{Mlt}}\nolimits(M(q))) = q + 1`$ for $`q = 2^f`$ (rank $`3`$ with subdegrees $`1, 56, 63`$ for $`M(2)`$ on $`120`$ points) and $`\frac{q + 3}{2}`$ for odd $`q`$ (rank $`3`$ with subdegrees $`1, 351, 728`$ for $`M(3)`$ on $`1080`$ points, unbounded as $`q \to \infty`$). Indeed, for odd $`q`$, since $`-I_8 \in Z(\Omega_8^+(q))`$ ($`\det(-I_8) = +1`$, spinor norm $`[-1]^4 = [+1]`$), every $`\hat{g} \in \Omega_8^+(q)`$ stabilizing $`\{\pm 1\}`$ shares its image in $`\mathop{\mathrm{P\Omega}}\nolimits_8^+(q) = \Omega_8^+(q)/\{\pm I_8\}`$ with a unique lift fixing $`+1`$, giving $`\mathop{\mathrm{Stab}}\nolimits_{\mathop{\mathrm{P\Omega}}\nolimits_8^+(q)}(\{\pm 1\}) \cong \Omega(V_7) = \Omega_7(q)`$ on $`V_7 = 1^\perp`$ ($`N(z) = -z^2`$). By Witt's Theorem and spinor-norm surjectivity of $`\mathop{\mathrm{SO}}\nolimits_5(q)`$ and $`\mathop{\mathrm{SO}}\nolimits_6^\varepsilon(q)`$, $`\Omega_7(q)`$ acts transitively on $`\{0 \neq z \in V_7 : N(z) = 0\}`$ and on $`\{z \in V_7 : N(z) = c\}`$ for every $`c \in \mathbb{F}_q^\times`$: writing $`\{\pm(t \cdot 1 + z)\}`$ ($`t \in \mathbb{F}_q, z \in V_7, N(z) = 1 - t^2`$) yields $`2`$ orbits at $`t = \pm 1`$ ($`z = 0`$ of size $`1`$, and $`0 \neq z`$ singular of size $`q^6 - 1`$), $`1`$ orbit at $`t = 0`$ ($`N(z) = 1`$), and $`1`$ orbit for each of the $`\frac{q - 3}{2}`$ pairs $`\{\pm t\} \subset (\mathbb{F}_q \setminus \{0, \pm 1\})/\{\pm 1\}`$, totaling $`2 + 1 + \frac{q - 3}{2} = \frac{q + 3}{2}`$ (`code/verify_wave2_folder_s1.py`).
   For $`q`$ even, put $`e=1`$ and $`t=B(e,y)`$ for $`N(y)=1`$. Witt's extension theorem shows that $`O_8^+(q)_e`$ is transitive on each fiber with $`t\ne0`$ and on the fiber with $`t=0`$ after removing $`e`$: the map $`e\mapsto e`$, $`y\mapsto y'`$ is an isometry of the spans, including the degenerate $`t=0`$ case. These orbits do not split on passage to $`\Omega_8^+(q)_e`$. Indeed the common stabilizer of $`e,y`$ contains a symmetry with nontrivial Dickson invariant: for $`t=0`$ take the symmetry centered at the nonsingular vector $`e`$; for $`t\ne0`$, take one centered at a nonsingular vector of the nondegenerate six-dimensional space $`\langle e,y\rangle^\perp`$. Composing a Witt extension with this symmetry if necessary places it in $`\Omega_8^+(q)_e`$. Each fiber occurs: in a hyperbolic basis $`u_i,v_i`$ with $`e=u_1+v_1`$, the vector $`y_t=u_1+(1+t)v_1+u_2+t v_2`$ has $`N(y_t)=1`$ and $`B(e,y_t)=t`$, and $`y_0\ne e`$. Thus the orbits are $`\{e\}`$, the rest of the $`t=0`$ fiber, and one for each $`t\ne0`$, giving $`q+1`$ in all. The case $`q=2`$ has subdegrees $`1,56,63`$.
2. **Hurwitz–Paige Moufang Collapse on nonsingular $`\mathbb{F}_2`$-quadrics**:
   Let $`(V, Q)`$ be a nondegenerate quadratic space of dimension $`2m`$ over $`\mathbb{F}_2`$ with sign $`\varepsilon \in \{+, -\}`$ and $`(2m, \varepsilon) \notin \{(2, \pm), (4, +)\}`$ (covering all almost-simple rank-$`3`$ actions $`\Omega_{2m}^\varepsilon(2) \le P \le O_{2m}^\varepsilon(2)`$ on $`\Omega = \{y \in V : Q(y) = 1\}`$, including $`O_6^-(2) = \mathop{\mathrm{Aut}}\nolimits(\mathop{\mathrm{PSU}}\nolimits_4(2))`$ on $`36`$ points — where Lemma 2.1(1) already leaves $`0/1440`$ coset elements on $`\Delta_{15}`$ and $`4/1440`$ on $`\Delta_{20}`$ — $`O_8^+(2)`$ on $`120`$ points, $`O_8^-(2)`$ on $`136`$ points, and all $`2m \ge 6`$; for $`(8, +)`$, triality moves $`\Omega`$ to the two triality-image $`120`$-sets, so $`\mathop{\mathrm{Stab}}\nolimits_{\mathop{\mathrm{Aut}}\nolimits(\Omega_8^+(2))}(\Omega) = O_8^+(2)`$). Let $`(Q_{\text{loop}}, *)`$ be **any** loop on $`\Omega`$ ($`e \in \Omega`$ identity) with $`\mathop{\mathrm{Mlt}}\nolimits(Q_{\text{loop}}) \le O(V, Q)`$.
   - **(a) Vanishing Lemma**: No nonzero polynomial $`D : V \to \mathbb{F}_2`$ of multilinear degree $`\le 2`$ with $`D(0) = 0`$ vanishes on $`\Omega`$.
     *Proof*: For $`(4,-)`$, take $`Q=x_1x_2+x_3^2+x_3x_4+x_4^2`$. The ten vectors with $`Q=1`$ are $`0001,0010,0011,0101,0110,0111,1001,1010,1011,1100`$. Evaluating the ten monomials $`x_1,x_2,x_3,x_4,x_1x_2,x_1x_3,x_1x_4,x_2x_3,x_2x_4,x_3x_4`$ in that order yields rows $`0001000000,0010000000,0011000001,0101000010,0110000100,0111000111,1001001000,1010010000,1011011001,1100100000`$. This $`10\times10`$ matrix has determinant $`1`$ over $`\mathbb F_2`$, giving rank $`10`$. For $`(6,+)`$, the direct rank check in `code/verify_wave2_folder_s1.py` gives rank $`21=6+\binom 62`$ on the $`28`$ vectors with $`Q=1`$; its $`22`$ columns including the constant have rank $`21`$; on $`Q=1`$ the constant column equals the sum of the three hyperbolic quadratic columns, so the $`21`$ zero-constant columns are independent. Inductively, write $`V = (\mathbb{F}_2 u \oplus \mathbb{F}_2 v) \perp W`$ ($`Q(a u + b v + w) = a b + Q_W(w)`$) with $`(W, Q_W)`$ satisfying the hypothesis, and $`D(a u + b v + w) = \alpha a + \beta b + \gamma a b + a \ell_1(w) + b \ell_2(w) + D_W(w)`$ vanishing when $`a b + Q_W(w) = 1`$. Setting $`(a, b) = (0, 0)`$ gives $`D_W \equiv 0`$ by IH; $`(a, b) = (1, 0)`$ gives $`(\alpha Q_W + \ell_1)|_{\{Q_W = 1\}} = 0 \implies \alpha Q_W + \ell_1 \equiv 0`$ by IH, and polarizing gives $`\alpha B_W(w_1, w_2) = 0`$ ($`\forall w_1, w_2 \in W`$), whence $`\alpha = 0`$ (as $`B_W \neq 0`$) and $`\ell_1 = 0`$; symmetrically $`(a, b) = (0, 1) \implies \beta = 0, \ell_2 = 0`$; finally $`(a, b, w) = (1, 1, 0)`$ gives $`\gamma = 0`$.
   - **(b) Clifford Quadratic Equations and Automatic RIP (Moufang Collapse)**: For each $`x \in \Omega \setminus \{e\}`$, `C0008` Lemma 2.1(1) gives $`B(y, L_x(y)) = B(e, x) = B(e, x) Q(y)`$ for all $`y \in \Omega`$. Applying (a) to $`D(y) := B(y, L_x(y)) + B(e, x) Q(y)`$ gives $`B(y, L_x(y)) = B(e, x) Q(y)`$ on all of $`V`$. Polarizing yields $`L_x^* + L_x = B(e, x) I_V`$; multiplying on the right by $`L_x`$ (using $`L_x^* L_x = I_V`$) and symmetrically for $`R_x`$ yields
     $$L_x^2 + B(e, x) L_x + I_V = 0 \quad \text{and} \quad R_x^2 + B(e, x) R_x + I_V = 0 \qquad \forall x \in \Omega \setminus \{e\}.$$
     If $`B(e, x) = 0`$ ($`x \neq e`$), then $`L_x^2 = R_x^2 = I_V`$, so $`x^{-1} = L_x^{-1}(e) = L_x(e) = x`$ and $`R_{x^{-1}} = R_x = R_x^{-1}`$. If $`B(e, x) = 1`$, then $`L_x^3 = R_x^3 = I_V`$ and $`x^{-1} = L_x^{-1}(e) = L_x^2(e) = (I_V + L_x)(e) = e + x \in \Omega`$; for every $`z \in \Omega`$, $`\mathbb{F}_2`$-linearity of $`L_z \in O(V, Q)`$ gives
     $$R_{x^{-1}}(z) = L_z(e + x) = L_z(e) + L_z(x) = z + R_x(z) = (I_V + R_x)(z) = R_x^2(z) = R_x^{-1}(z).$$
     Hence $`(Q_{\text{loop}}, *)`$ satisfies RIP ($`R_{x^{-1}} = R_x^{-1}`$ for all $`x \in \Omega`$); by `C0001` Proposition 1.1(2), **every left Bol loop on $`\Omega`$ with $`\mathop{\mathrm{Mlt}}\nolimits(Q_{\text{loop}}) \le O_{2m}^\varepsilon(2)`$ is Moufang (zero proper left Bol loops exist)**.
   - **(c) Unital Composition Algebra Extension and Uniqueness of $`M(2)`$**: By (a), $`\mathop{\mathrm{Span}}\nolimits_{\mathbb{F}_2}(\Omega) = V`$, and for any $`\mathbb{F}_2`$-linear relation $`\sum c_i x_i = 0`$ ($`x_i \in \Omega`$) and any $`y \in \Omega`$, $`\mathbb{F}_2`$-linearity of $`R_y \in O(V, Q)`$ gives $`\sum c_i L_{x_i}(y) = \sum c_i R_y(x_i) = R_y(\sum c_i x_i) = 0`$, so $`*`$ extends uniquely to an $`\mathbb{F}_2`$-bilinear unital product $`\star : V \times V \to V`$ with identity $`e`$. For each $`v \in V`$, $`D_v(u) := Q(u \star v) + Q(u) Q(v)`$ has multilinear degree $`\le 2`$, $`D_v(0) = 0`$, and vanishes for $`u \in \Omega`$ ($`L_u \in O(V, Q)`$), so $`D_v \equiv 0`$ by (a), i.e. $`Q(u \star v) = Q(u) Q(v)`$ ($`\forall u, v \in V`$). Palermo* (2) **7** (1958), 55–80), $`2m \in \{1, 2, 4, 8\}`$ and split Witt index is forced over $`\mathbb{F}_2`$, so **zero loops exist for $`(4, -)`$, all $`2m = 6`$ ($`n = 28, 36`$), $`(8, -)`$ ($`n = 136`$), and all $`2m \ge 10`$**, while at $`(8, +)`$ ($`n = 120`$) **Paige's simple Moufang loop $`M(2)`$ is the unique loop**. $`\square`$
