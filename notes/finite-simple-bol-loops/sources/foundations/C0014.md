# Proof of C0014: CFSG-Free O'Nan-Scott Structural Reduction and Type HA, SD_2, HC-B, HS, PA Exclusions for Primitive LMlt(Q)

Claim: `0323-finite-simple-non-moufang-bol-loops:C0014`

We work throughout in the faithful left Bol folder $`(G, H, K)`$ of a finite nonassociative left Bol loop $`(Q, *)`$ (`0323-finite-simple-non-moufang-bol-loops:C0001`), without invoking `CFSG`.

### 1. Universal Loop-Simplicity and External Twisted Semidirect Product

1. **Primitivity of $`\mathop{\mathrm{LMlt}}\nolimits(Q)`$ implies loop-simplicity of $`Q`$**:
   Suppose $`1_Q \neq N \lneq Q`$ is a proper nontrivial normal subloop of any loop $`Q`$ ($`|Q| \ge 2`$), with quotient homomorphism $`\pi : Q \twoheadrightarrow Q / N`$. For all $`x, y \in Q`$, $`\pi(L_x(y)) = \pi(x * y) = \pi(x) * \pi(y)`$ depends only on $`\pi(x)`$ and $`\pi(y)`$, so each $`L_x`$ ($`x \in Q`$) — and hence $`G = \langle L_x : x \in Q \rangle`$ — permutes the fibers of $`\pi`$ as a nontrivial block system ($`1 < |N| < |Q|`$), contradicting primitivity of $`G`$. For finite nonassociative left Bol $`Q`$, `0323-finite-simple-non-moufang-bol-loops:C0001` Theorem 1.5(1) gives $`N_\lambda(Q) = \{1_Q\}`$, and `0323-finite-simple-non-moufang-bol-loops:C0008` Theorem 1.2 gives Almost-Simple (`AS`) primitivity of $`\mathop{\mathrm{Mlt}}\nolimits(Q)`$.

2. **External twisted semidirect product $`\widetilde{G}_{\mathrm{ext}}`$**:
   Let $`\tau \in \mathop{\mathrm{Aut}}\nolimits(G)`$ ($`\tau^2 = \mathrm{id}_G`$, $`\tau(k) = k^{-1}`$ for all $`k \in K`$) be the canonical inverting automorphism of `0323-finite-simple-non-moufang-bol-loops:C0007` Theorem 1.1(1). Form the external semidirect product $`\widetilde{G}_{\mathrm{ext}} := G \rtimes_\tau \langle t \rangle \cong G \rtimes C_2`$ ($`t \notin G`$, $`t^2 = 1`$, $`t g t = \tau(g)`$ for all $`g \in G`$), and put $`\Lambda := t K \subseteq t G`$ (keeping $`t`$ external even when $`\exp(Q) = 2`$ and $`\tau = \mathrm{id}_G`$).
   - Every $`\lambda = t k \in \Lambda`$ satisfies $`\lambda^2 = \tau(k) k = k^{-1} k = 1`$, $`t = t \cdot 1_G \in \Lambda`$, $`|\Lambda| = |K| = [G : H]`$, and $`\langle \Lambda \rangle = \widetilde{G}_{\mathrm{ext}}`$ since $`k = t(t k) \in \Lambda^2`$ for all $`k \in K`$ and $`\langle K \rangle = G`$.
   - For all $`\lambda_1 = t k_1, \lambda_2 = t k_2 \in \Lambda`$,
     $$\lambda_1 \lambda_2 \lambda_1 = (t k_1)(t k_2)(t k_1) = k_1^{-1} k_2 t k_1 = t \, \tau(k_1^{-1} k_2) k_1 = t(k_1 k_2^{-1} k_1) \in t K = \Lambda$$
     because $`k_2^{-1} \in K`$ (LIP) and $`a b a \in K`$ for all $`a, b \in K`$. Since $`\langle \Lambda \rangle = \widetilde{G}_{\mathrm{ext}}`$, $`\Lambda`$ is a union of $`\widetilde{G}_{\mathrm{ext}}`$-conjugacy classes of involutions in $`t G`$ (in particular, $`\lambda^B \subseteq \Lambda`$ for every subgroup $`B \le G`$ and $`\lambda \in \Lambda`$).
   - $`\Lambda^2 = K^{-1} K \subseteq G`$ satisfies $`H \cap \Lambda^2 = \{1_G\}`$. If $`G_+ \trianglelefteq G`$ has index $`[G : G_+] = 2`$, $`\Lambda`$ cannot lie in a single $`G_+`$-coset inside $`t G`$: otherwise $`t \in \Lambda \implies \Lambda \subseteq t G_+ \implies K = t \Lambda \subseteq G_+ \lneq G`$, contradicting $`\langle K \rangle = G`$. $`\square`$

### 2. Complete `CFSG`-Free Elimination of Types `HA` and `SD_2`

1. **Holomorph Affine (`HA`)**:
   If $`G = \mathop{\mathrm{LMlt}}\nolimits(Q)`$ acts primitively of type `HA` on a finite nonassociative left Bol loop $`Q`$, then $`|Q| = p^d`$ for a prime $`p \ge 2`$ and $`d \ge 1`$, and $`Q`$ is loop-simple by Part 1(1). By `0323-finite-simple-non-moufang-bol-loops:C0011` Part 1 (`100% CFSG-free`), no finite simple nonassociative left Bol loop has prime-power order $`p^d`$, a contradiction.

2. **Simple Diagonal `SD_2`**:
   Suppose $`G = \mathop{\mathrm{LMlt}}\nolimits(Q)`$ acts primitively of type `SD_2` on $`Q`$, with unique minimal normal subgroup $`B = \mathop{\mathrm{Soc}}\nolimits(G) = T_1 \times T_2 \cong T^2`$ ($`T`$ finite nonabelian simple), $`H \cap B = \Delta(T)`$, and $`|Q| = [G : H] = |T| \ge 60`$. By Part 1(1), $`Q`$ is loop-simple, and $`Q`$ is nonassociative since $`|G| > |B| = |T|^2 > |T| = |Q|`$. Because $`B`$ is minimal normal in $`G`$ (unlike `HS`), $`G_+ := N_G(T_1) = N_G(T_2) \trianglelefteq G`$ has index $`[G : G_+] = 2`$. Since $`B = \mathop{\mathrm{Soc}}\nolimits(G)`$ is characteristic in $`G`$ and $`\{T_1, T_2\}`$ are the unique minimal normal subgroups of $`B`$, conjugation in $`\widetilde{G}_{\mathrm{ext}}`$ permutes $`\{T_1, T_2\}`$ via $`\tilde{\pi} : \widetilde{G}_{\mathrm{ext}} \twoheadrightarrow S_2`$ with $`\ker(\tilde{\pi}) \cap G = G_+`$.
   - *Subcase 1*: Every $`\lambda \in \Lambda`$ satisfies $`\tilde{\pi}(\lambda) = \tilde{\pi}(t)`$. Then every $`k = t(t k) \in K`$ lies in $`\ker(\tilde{\pi}) \cap G = G_+`$, contradicting $`\langle K \rangle = G`$.
   - *Subcase 2*: Some $`\lambda_0 \in \Lambda`$ swaps $`T_1 \leftrightarrow T_2`$. Since $`\lambda_0^2 = 1`$, $`\lambda_0(x_1, x_2)\lambda_0^{-1} = (\psi^{-1}(x_2), \psi(x_1))`$ for an isomorphism $`\psi : T_1 \xrightarrow{\sim} T_2`$, so $`C_B(\lambda_0) = \{(x_1, \psi(x_1)) : x_1 \in T\}`$ has order $`|T|`$. By Part 1(2), $`(\lambda_0)^B \subseteq \Lambda`$ has cardinality $`|B| / |C_B(\lambda_0)| = |T|^2 / |T| = |T| = |\Lambda|`$, forcing $`\Lambda = (\lambda_0)^B \subseteq \lambda_0 B \subseteq \lambda_0 G_+`$, a single $`G_+`$-coset in $`t G`$, contradicting Part 1(2)! $`\square`$

### 3. Holomorph Simple Type `HS` (`CFSG`-Free Reduction & Alternating / Single-Involution-Class Elimination)

Let $`B = \mathop{\mathrm{Soc}}\nolimits(G) = T_1 \times T_2 \cong T^2`$ with $`T_1 \trianglelefteq G, T_2 \trianglelefteq G`$, $`G = (T \times T)\Delta(A)`$, $`H = \Delta(A)`$ ($`\mathop{\mathrm{Inn}}\nolimits(T) \le A \le \mathop{\mathrm{Aut}}\nolimits(T)`$), and $`|Q| = |\Lambda| = |T|`$. Since $`\{T_1, T_2\}`$ are the unique minimal normal subgroups of $`G`$, $`\tau`$ either swaps $`T_1 \leftrightarrow T_2`$ (**Case B**) or preserves each $`T_i`$ (**Case A**).

1. **Case B ($`\tau(T_1) = T_2, \tau(T_2) = T_1`$)**:
   Conjugation by $`t \in \Lambda`$ takes $`t(x_1, x_2)t^{-1} = (\theta^{-1}(x_2), \theta(x_1))`$ for some $`\theta \in \mathop{\mathrm{Aut}}\nolimits(T)`$, so $`|C_B(t)| = |\{(x, \theta(x)) : x \in T\}| = |T|`$ and $`|t^B| = |T|^2 / |T| = |T| = |\Lambda|`$, forcing $`\Lambda = t^B`$. For $`(z_1, z_2) \in B`$, $`t \cdot (z_1, z_2) t (z_1^{-1}, z_2^{-1}) = (\theta^{-1}(z_2) z_1^{-1}, \theta(z_1) z_2^{-1}) = (u, \theta(u)^{-1})`$ with $`u = \theta^{-1}(z_2) z_1^{-1} \in T`$, so $`K = K_\theta := \{(u, \theta(u)^{-1}) : u \in T\} \subseteq B`$. Since $`\langle K \rangle = G`$, $`G = T \times T`$ and $`H = \Delta(T)`$ (if $`\langle K_\theta \rangle \lneq T \times T`$, Goursat's Lemma gives $`\langle K_\theta \rangle = \{(u, \psi(u)) : u \in T\}`$ for an isomorphism $`\psi`$, making $`u \mapsto u^{-1} = \theta^{-1}(\psi(u))`$ a homomorphism and $`T`$ abelian, impossible). Clearly $`(1, 1) \in K_\theta`$ and $`a b a \in K_\theta`$ ($`\forall a, b \in K_\theta`$). Every conjugate of $`H = \Delta(T)`$ in $`T \times T`$ is $`H_c = \{(c x c^{-1}, x) : x \in T\}`$ ($`c \in T`$). For $`u_1 \neq u_2`$ in $`T`$, set $`v := u_1^{-1} u_2 \neq 1_T`$; then $`(u_1, \theta(u_1)^{-1})^{-1}(u_2, \theta(u_2)^{-1}) = (v, \theta(u_1)\theta(v)^{-1}\theta(u_1)^{-1})`$ lies in some $`H_c`$ iff $`v`$ is $`T`$-conjugate to $`\theta(v)^{-1}`$, i.e., iff $`\theta(v) \in (v^{-1})^T`$. In particular, if $`v \in \mathcal{I}_0`$ lies in an $`\mathop{\mathrm{Aut}}\nolimits(T)`$-invariant involution class, $`\theta(v) \in \mathcal{I}_0 = v^T = (v^{-1})^T`$, violating transversality.

2. **Case A ($`\tau(T_1) = T_1, \tau(T_2) = T_2`$) — Non-degeneracy**:
   Partition $`\Lambda = \Lambda_0 \sqcup \Lambda_1 \sqcup \Lambda_2 \sqcup \Lambda_{12}`$ according to whether $`\alpha_1(\lambda)`$ and/or $`\alpha_2(\lambda)`$ equal $`\mathrm{id}_T`$. Suppose $`\Lambda_{12} = \emptyset`$. In $`G = (T \times T)\Delta(A)`$, $`(u_1 \gamma, u_2 \gamma)`$ centralizes $`T_2`$ iff $`u_2 \gamma = \mathrm{id}_T \iff \gamma = u_2^{-1} \in T`$, so $`C_G(T_2) = T_1 \times \{1\}`$ and $`C_G(T_1) = \{1\} \times T_2`$. If $`\Lambda_1 \cup \Lambda_0 \neq \emptyset`$, fix $`\lambda_1 \in \Lambda_1 \cup \Lambda_0`$ with $`\theta_1 := \alpha_1(\lambda_1)`$. Every $`\lambda \in \Lambda_1 \cup \Lambda_0`$ satisfies $`\lambda_1^{-1}\lambda \in C_G(T_2) = T_1 \times \{1\}`$, so $`\lambda = \lambda_1(s, 1)`$ with $`1 = \lambda^2 = (\theta_1(s) s, 1)`$, i.e. $`s \in S_{\theta_1} := \{s \in T : \theta_1(s) = s^{-1}\}`$; hence $`|\Lambda_1 \cup \Lambda_0| \le |S_{\theta_1}|`$ and symmetrically $`|\Lambda_2 \cup \Lambda_0| \le |S_{\theta_2}|`$ whenever the respective set is nonempty. If either set is empty, its cardinality is zero; the bound below then applies directly without choosing the corresponding $`\theta_i`$.

   For any $`\theta \in \mathop{\mathrm{Aut}}\nolimits(T)`$ with $`\theta^2 = \mathrm{id}_T`$ and $`(s, x) \in S_\theta \times T`$, $`s x \in S_\theta \iff s x s^{-1} = \theta(x)^{-1}`$. For $`x = 1_T`$ there are $`|S_\theta|`$ pairs; for each $`1_T \neq x \in T`$, $`\{g \in T : g x g^{-1} = \theta(x)^{-1}\}`$ is empty or a coset of $`C_T(x)`$. Because $`T`$ is nonabelian simple and $`S_4`$ is solvable, $`[T : C_T(x)] \ge 5`$ ($`\forall 1_T \neq x \in T`$) and $`|T| \ge 60`$. Summing over $`x \in T`$ gives
   $$|S_\theta|^2 = \sum_{x \in T} \bigl|\{s \in S_\theta : s x s^{-1} = \theta(x)^{-1}\}\bigr| \le |S_\theta| + \frac{|T|(|T| - 1)}{5} < |S_\theta| + \frac{|T|^2}{5},$$
   so $`|S_\theta|^2 - |S_\theta| < \frac{1}{5}|T|^2`$. If $`|S_\theta| \ge \frac{1}{2}|T|`$, monotonicity of $`x \mapsto x^2 - x`$ on $`[1/2, \infty)`$ yields $`\frac{1}{4}|T|^2 - \frac{1}{2}|T| \le |S_\theta|^2 - |S_\theta| < \frac{1}{5}|T|^2 \implies \frac{1}{20}|T|^2 < \frac{1}{2}|T| \implies |T| < 10`$, contradicting $`|T| \ge 60`$. Since $`|S_\theta|`$ is an integer strictly below $`\frac{1}{2}|T|`$, $`|S_\theta| \le \frac{|T| - 1}{2}`$, giving
   $$|\Lambda| \le |\Lambda_1 \cup \Lambda_0| + |\Lambda_2 \cup \Lambda_0| \le 2\cdot\frac{|T|-1}{2} = |T| - 1 < |T| = |\Lambda|,$$
   contradiction! Thus $`\Lambda_{12} \neq \emptyset`$. Pick $`\lambda_* \in \Lambda_{12}`$ inducing $`(\alpha_1, \alpha_2)`$ ($`\alpha_i \neq \mathrm{id}_T`$). From $`(\lambda_*)^B \subseteq \Lambda`$ we obtain $`[T : C_T(\alpha_1)][T : C_T(\alpha_2)] \le |T|`$, i.e. $`|C_T(\alpha_1)| \cdot |C_T(\alpha_2)| \ge |T|`$. For $`(u_1, u_2), (v_1, v_2) \in B`$ with $`w_i := u_i^{-1} v_i`$,
   $$\bigl((u_1, u_2) \lambda_* (u_1^{-1}, u_2^{-1})\bigr)\bigl((v_1, v_2) \lambda_* (v_1^{-1}, v_2^{-1})\bigr) = \bigl(u_1 \alpha_1(w_1) w_1^{-1} u_1^{-1},\; u_2 \alpha_2(w_2) w_2^{-1} u_2^{-1}\bigr),$$
   so $`\mathcal{C}(\alpha_1) \times \mathcal{C}(\alpha_2) = (\lambda_*^B)^2 \subseteq \Lambda^2 \cap B`$. Intersecting with $`\Delta(T) = H \cap B`$ and using $`H \cap \Lambda^2 = \{1_G\}`$ forces $`\mathcal{C}(\alpha_1) \cap \mathcal{C}(\alpha_2) = \{1_T\}`$.

3. **Case A — Elimination of all $`A_m`$ ($`m \ge 5`$) and all single-involution-class simple groups**:
   - *$`T = A_m`$ ($`m \ge 5`$)*: For $`m \neq 6`$, $`\mathop{\mathrm{Aut}}\nolimits(A_m) = S_m`$; every involution $`1 \neq \alpha \in S_m`$ lies in $`C_k`$ ($`1 \le k \le \lfloor m/2 \rfloor`$), commutes with one of its own transpositions in $`S_m \setminus A_m`$ so $`\alpha^{A_m} = C_k`$, and satisfies $`C_2 \subseteq C_k^2 = \mathcal{C}(\alpha)`$ by `0323-finite-simple-non-moufang-bol-loops:C0007` Proof Lemma 3.2 ($`\lfloor m/4 \rfloor \ge 1`$). Thus $`C_2 \subseteq \mathcal{C}(\alpha_1) \cap \mathcal{C}(\alpha_2) \neq \{1\}`$. At $`m = 6`$, $`A_6`$ has a single involution class, covered by the next bullet (and verified directly on $`\mathop{\mathrm{Aut}}\nolimits(A_6) = \mathop{\mathrm{P\Gamma L}}\nolimits_2(9)`$ in `verify_wave2_folder_s1.py`).
   - *Single involution class $`\mathcal{I}(T)`$*: The general square-class lemma in [the SD₃ manuscript](../primitive-completion/sd3-involution-count.md#candidate-extension-all-psl₂q) states that for every nonidentity involutory $`\alpha\in\mathop{\mathrm{Aut}}\nolimits(T)`$, $`\mathcal{I}(T)\subseteq(\alpha^T)^2=\mathcal{C}(\alpha)`$. Applying it to $`\alpha_1`$ and $`\alpha_2`$ gives $`\mathcal{I}(T)\subseteq\mathcal{C}(\alpha_1)\cap\mathcal{C}(\alpha_2)\ne\{1_T\}`$, contradicting Part 3(2). $`\square`$

### 4. Types `HC`, `PA`, `SD_{k >= 3}`, `CD`, and `TW`

1. **`HC` Case B ($`\tau(B_1) = B_2, \tau(B_2) = B_1`$, where $`B = B_1 \times B_2`$, $`B_i \cong T^\ell`$ minimal normal in $`G`$, $`\ell \ge 2`$, $`|Q| = |T|^\ell`$)**:
   Conjugation by $`t \in \Lambda`$ swaps $`B_1 \leftrightarrow B_2`$ via $`t(x_1, x_2)t^{-1} = (\Theta^{-1}(x_2), \Theta(x_1))`$ ($`\Theta : B_1 \xrightarrow{\sim} B_2`$), so $`|C_B(t)| = |B_1| = |T|^\ell`$ and $`|t^B| = |T|^{2\ell} / |T|^\ell = |T|^\ell = |\Lambda|`$. Hence $`\Lambda = t^B \subseteq t B`$ and $`K = t \Lambda \subseteq B`$. In type `HC` with $`\ell \ge 2`$, $`G / B`$ acts transitively on the $`\ell \ge 2`$ simple factors of $`B_1`$, so $`B \lneq G`$ strictly, contradicting $`\langle K \rangle = G`$!

2. **Existence of factor-swapping involution $`\lambda_* \in \Lambda`$**:
   In `SD_{k \ge 3}, CD, PA, TW` ($`B \cong T^m`$ minimal normal in $`G`$, $`m \ge 2`$) and `HC` Case A ($`B = B_1 \times B_2`$, $`B_i \cong T^\ell`$ minimal normal in $`G`$, $`\ell \ge 2`$), $`G`$ acts nontrivially by conjugation on the $`m`$ simple factors of $`B`$. Since $`\langle \Lambda \rangle = \widetilde{G}_{\mathrm{ext}} \ge G`$ and $`\lambda^2 = 1`$ ($`\forall \lambda \in \Lambda`$), some $`\lambda_* \in \Lambda`$ induces a nontrivial involution $`\pi_* = \tilde{\pi}(\lambda_*) \in S_m`$ ($`r \ge 1`$ transpositions). Computing $`|C_B(\lambda_*)| = |T|^r \prod_{\pi_*(s)=s} |C_T(\alpha_s)|`$ and using $`(\lambda_*)^B \subseteq \Lambda`$ yields $`|T|^r \prod_{\pi_*(s)=s} [T : C_T(\alpha_s)] \le [G : H]`$.

3. **`PA` double-coset exclusion and invariant-involution criteria**:
   - In `PA` ($`H \cap B = R^\ell`$, $`1_T \neq R \lneq T`$), relabel so $`\pi_*(1) = 2`$ with $`\lambda_*(x_1, x_2, 1, \dots, 1)\lambda_*^{-1} = (\theta^{-1}(x_2), \theta(x_1), 1, \dots, 1)`$. For $`g \in T`$ and $`u \in R`$, put $`b_1 = (1, g^{-1}, 1, \dots, 1) \in B`$ and $`b_2 = (u, g^{-1}, 1, \dots, 1) \in B`$. Then
     $$(b_1 \lambda_* b_1^{-1})(b_2 \lambda_* b_2^{-1}) = (u^{-1}, g^{-1} \theta(u) g, 1, \dots, 1) \in \Lambda^2 \cap B.$$
     If $`g^{-1} \theta(u) g \in R`$, this element lies in $`(H \cap B) \cap \Lambda^2 = \{1_B\}`$, forcing $`u = 1_T`$. Thus $`R \cap g \theta(R) g^{-1} = \{1_T\}`$ for all $`g \in T`$. Setting $`g = 1_T`$ gives $`|R|^2 = |R \cdot \theta(R)| \le |T|`$, so $`d = [T : R] \ge |T|^{1/2}`$; if $`v \in R \cap \mathcal{I}_0`$ for an $`\mathop{\mathrm{Aut}}\nolimits(T)`$-invariant involution class $`\mathcal{I}_0`$, $`\theta(v) \in v^T`$ gives $`v = g \theta(v) g^{-1} \in R \cap g \theta(R) g^{-1} \setminus \{1_T\}`$, contradiction.
   - In `SD_{2r}` with $`f = 0`$ ($`H \cap B = \Delta(T)`$), applying the same pair calculation simultaneously on each transposed pair $`(T_{2j-1}, T_{2j})`$ ($`1 \le j \le r`$) with $`v \in \mathcal{I}_0`$ and $`g_{2j}^{-1}\theta_j(v)g_{2j} = v`$ yields $`(v, \dots, v) \in (H \cap B) \cap (\lambda_*^B)^2 \setminus \{1_B\}`$, contradiction.
   - In `HC` Case A ($`H \cap B = \{(x_1, \dots, x_\ell;\, x_1, \dots, x_\ell)\}`$), if $`\pi_1(\lambda_*)`$ and $`\pi_2(\lambda_*)`$ both transpose $`1 \leftrightarrow 2`$ via $`\theta_1, \theta_2`$, choosing $`v \in \mathcal{I}_0`$ and $`g_r^{-1}\theta_r(v)g_r = v`$ ($`r = 1, 2`$) with $`b_1 = (1, g_1^{-1}, 1, \dots, 1;\, 1, g_2^{-1}, 1, \dots, 1)`$ and $`b_2 = (v, g_1^{-1}, 1, \dots, 1;\, v, g_2^{-1}, 1, \dots, 1)`$ produces $`(v, v, 1, \dots, 1;\, v, v, 1, \dots, 1) \in (H \cap B) \cap (\lambda_*^B)^2 \setminus \{1_B\}`$, contradiction. $`\square`$
