# Code and reproducibility

## Public reproduction layout

The exact programs retain their original repository-relative paths. Before running the commands below, stage them with `python stage_classification.py /tmp/bol-classification-run` from this directory, then change to that new workspace. The destination must not already exist. The staging helper verifies public hashes and recreates `problems/0323-finite-simple-non-moufang-bol-loops/code/` without modifying the pinned programs. It performs no computation or downloads. GAP, compilers and other named dependencies must be installed separately. The imported repository-wide `check.py` commands are not available in this public staging workspace.


This directory contains a dependency-free, exact computational suite for finite left Bol loops, faithful left Bol folders $`(G, H, K)`$, exact-factorization loops $`Q_{(X, Y_0, Y_1)}`$, isotopy-orbit censuses, multiplication-group and automorphism-group structure, and `#0323/S1` rank-obstruction experiments.

## Reproducibility

### Simplicity, isomorphism, and automorphism certification

- **Dual exact simplicity certification (`Loop.check_simplicity`)**: Never tests mere absence of proper subloops. Every simplicity call executes **both** independent exact algorithms and asserts agreement:
  1. *Direct loop-congruence / normal-subloop generation*: for **every** $`a \in Q \setminus \{0\}`$, computes the smallest equivalence relation with $`a \sim 0`$ closed under $`\{L_x, R_x, L_x^{-1}, R_x^{-1} : x \in Q\}`$, and for $`n \le 300`$ explicitly verifies compatibility of $`(*, \backslash, /)`$ on every nontrivial proper partition (`verify_is_loop_congruence`).
  2. *Primitivity of $`\mathop{\mathrm{Mlt}}\nolimits(Q)`$ on $`Q`$*: verifies via Atkinson's minimal-block algorithm on all $`a \neq 0`$ and `PermGroup.is_primitive()` that $`\mathop{\mathrm{Mlt}}\nolimits(Q)`$ admits no nontrivial proper blocks.
- **Isomorphism deduplication and $`\mathop{\mathrm{Aut}}\nolimits(Q)`$ (`deduplicate_loops`, `Loop.automorphisms`)**: Partitions loops by structural invariants (order, power-order histogram, $`L_x / R_x`$ cycle-type profiles, squaring profile, nuclei/commutant/center sizes) and resolves candidate pairs and full automorphism groups by exact forward-checking backtracking search over bijections $`\phi`$ satisfying $`\phi(x * y) = \phi(x) * \phi(y)`$.
