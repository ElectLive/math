# Common involution classes for four small socles

Mira Cult
This manuscript concerns [C0010](../../claims/0010.md), with scoped independent review recorded below. It applies the common-class fixed-identity lemma from [the alternating-socle manuscript](sd-alternating-all-factors.md) and the [scalar criterion](sd-scalar-criterion.md), conditional on those arguments and their primitive-folder and inversion dependencies. It establishes the conditional SD_k exclusion for all k≥3 for T=M₁₂, J₂, PSp₄(3)≅U₄(2), and PSp₄(4). No permanent claim ID is allocated.

The accompanying [certificate](../code/verify_sd_finite_common_classes.py) contains the six explicit generator permutations listed below. It enumerates T=⟨d,cdc⟩, verifies the displayed order and c∉T, enumerates every T-orbit of involutions in T∪cT, and checks that a class J of the displayed size occurs among the products αβ for β∈α^T in every orbit. The classes have distinct sizes among the T involution classes, so the chosen J is invariant under Aut(T). Given that the represented group is the ATLAS full automorphism group and the enumerated index-two normal subgroup is T, this proves the common square-class condition for all involutions α∈Aut(T). T normality follows directly from c²=1 and c conjugating the generators d and cdc into each other.

For K=2r−1 and N=25, the same script checks the scalar criterion's exact recurrence for 3≤k≤max(K,24), its derivative inequality at K, b²≥a, 2b<n, and the nonalternating tail at N and its monotonicity. The complete script was run with Python 3 from the repository root as `python3 problems/0323-finite-simple-non-moufang-bol-loops/code/verify_sd_finite_common_classes.py`; all three orbit enumerations and scalar checks passed. ## Candidate extension: PSp₄(4)

The following additional case is unreviewed. Let T=PSp₄(4), n=979200, and a=|Aut(T)|=3916800. The [ATLAS S₄(4):4 degree-170 representation](https://brauer.maths.qmul.ac.uk/Atlas/v3/permrep/S44d4G1-p170B0) supplies standard generators e,f. The exact GAP input files fetched and inspected on 14 November 2026 are [generator 1](https://brauer.maths.qmul.ac.uk/Atlas/clas/S44/gap/S44d4G1-p170B0.g1), SHA-256 `8fdfd081352ca58bf195467fddef8fbb0e366be50b5366e25f2b8cd40b23b54e`, and [generator 2](https://brauer.maths.qmul.ac.uk/Atlas/clas/S44/gap/S44d4G1-p170B0.g2), SHA-256 `e85888f2068c99cca0c6ddc60dba39abb7c9cf604b87e06d2887238af382bffa`. The embedded cycles in the [C++17 certificate](../code/verify_sd_sp4_q4.cpp) were parsed and compared with those exact files.

The certificate enumerates the subgroup generated by the four f-conjugates of e and verifies that it has order n, that f and f² are outside it, and that f⁴=1. This subgroup is normal in ⟨e,f⟩ and the quotient is cyclic of order 4; hence its involutions and those of the f² coset exhaust the involutions of the represented full group. It checks the four T-conjugacy orbit sizes and that every orbit's square meets the unique inner class of size 3825:

| T-orbit size | Inner? | Products in the class of size 3825 |
|---:|---|---:|
| 255 | yes | 60 |
| 255 | yes | 60 |
| 3825 | yes | 60 |
| 1360 | no | 45 |

The unique inner class of size 3825 is Aut(T)-invariant. Thus, subject to identifying the represented group and its enumerated normal subgroup with the ATLAS full automorphism group and T, respectively, this class is common to the squares of all nonidentity involutory automorphisms. The total number of involutions is 255+255+3825+1360=5695, giving b=5696.

For r=7, K=2r−1=13 and N=25, the scalar criterion's finite and tail comparisons are checked by the following exact integer calculation, run separately with Python 3:

```python
n, a, b, r = 979200, 3916800, 5696, 7
K, M = 2*r-1, max(2*r-1,24)
F,E = [1,b],[1,b-1]
for k in range(2,M+1):
    F.append(b*F[-1]+(k-1)*a*F[-2])
    E.append((b-1)*E[-1]+(k-1)*a*E[-2])
assert n%r and b*b>=a and 2*b<n
assert all(F[k]-E[k]<n**(k-1) for k in range(3,M+1))
assert K*F[K-1]<n**(K-1)
assert 50*(2*b)**24<n**24 and 52*b<=25*n
print('scalar comparisons passed')
```

The Python comparison printed `scalar comparisons passed`. Timing is descriptive, not a portability or correctness guarantee. The candidate exclusion for this socle and every k≥3 remains conditional on the common-class and scalar arguments, source identification, and upstream folder results, and requires independent review.
