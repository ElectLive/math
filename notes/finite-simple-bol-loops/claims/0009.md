# 0009: 0323/S1 Orbital Displacement Exclusions for Infinite Rank >= 3 Almost-Simple Families and Hurwitz-Paige Moufang Collapse on F_2-Quadrics

Mira Cult · Claim family 0009

**Status:** proved. **Recorded model-review status:** unreviewed.



## Statement

1. **Infinite rank $`\ge 3`$ combinatorial and classical subspace/polar `AS` exclusions**: No loop $`(Q, *)`$ has $`\mathop{\mathrm{Mlt}}\nolimits(Q) \le P`$ in any of the following primitive Almost-Simple (`AS`) actions of rank $`\ge 3`$:
   - Johnson-orbital actions on $`\binom{[m]}{k}`$ for any subgroup $`P \le \mathop{\mathrm{Aut}}\nolimits(A_m)`$ whose orbitals coincide with the Johnson distance orbitals, for all $`m \ge 5`$, $`2 \le k < m/2`$;
   - Uniform set partitions $`A_m \le P \le S_m`$ on $`\Pi_{a, b}`$ ($`m = a b`$, $`a, b \ge 2`$) outside the rank-$`2`$ cases $`(a, b) \in \{(2, 2), (3, 2)\}`$;
   - Linear Grassmannians $`\mathop{\mathrm{PSL}}\nolimits_d(q) \le P \le \mathop{\mathrm{Aut}}\nolimits(\mathop{\mathrm{PSL}}\nolimits_d(q))`$ on $`\mathcal{G}_k(\mathbb{F}_q^d)`$ for all $`d \ge 4`$, $`2 \le k \le d - 2`$, and all $`q = p^f`$ (including correlations at $`d = 2k`$);
   - Symplectic ($`\mathop{\mathrm{PSp}}\nolimits_{2m}(q) \le P \le \mathop{\mathrm{P\Gamma Sp}}\nolimits_{2m}(q)`$, $`m \ge 2`$), unitary ($`\mathop{\mathrm{PSU}}\nolimits_d(q_0) \le P \le \mathop{\mathrm{P\Gamma U}}\nolimits_d(q_0)`$, $`d \ge 4`$), and orthogonal ($`\mathop{\mathrm{P\Omega}}\nolimits_d^\varepsilon(q) \le P \le \mathop{\mathrm{P\Gamma O}}\nolimits_d^\varepsilon(q)`$, $`d \ge 5`$, Witt index $`w \ge 2`$) actions on isotropic/singular projective points and on totally isotropic/singular $`k`$-subspaces ($`2 \le k \le w`$ for $`\mathop{\mathrm{Sp}}\nolimits, U, O_{2w+1}, O_{2w+2}^-`$; $`2 \le k \le w - 1`$ and even-$`w`$ half-spin $`\mathcal{M}_\pm`$ for $`O_{2w}^+`$), as well as $`\mathop{\mathrm{Sp}}\nolimits_{2m}(2)`$ on $`\mathbb{F}_2^{2m} \setminus \{0\}`$.
2. **Paige $`M(q)`$ rank $`\ge 3`$ baseline and Hurwitz–Paige Moufang collapse on $`\mathbb{F}_2`$-quadrics**: Paige's simple Moufang loops $`M(q)`$ satisfy Uniform Orbital Displacement inside $`\mathop{\mathrm{P\Omega}}\nolimits_8^+(q)`$ at rank $`q + 1 \ge 3`$ ($`q = 2^f`$) and $`\frac{q + 3}{2} \ge 3`$ ($`q`$ odd, with rank $`3`$ and subdegrees $`1, 351, 728`$ for $`M(3)`$ on $`1080`$ points). Conversely, on the nonsingular points $`\Omega = \{y \in \mathbb{F}_2^{2m} : Q(y) = 1\}`$ ($`(2m, \varepsilon) \notin \{(2, \pm), (4, +)\}`$), **any** loop $`(Q_{\text{loop}}, *)`$ with $`\mathop{\mathrm{Mlt}}\nolimits(Q_{\text{loop}}) \le O_{2m}^\varepsilon(2)`$ satisfies $`L_x^2 + B(e, x) L_x + I_V = 0`$ and RIP (forcing every left Bol loop to be **Moufang**), extends to a unital composition algebra on $`(V, Q)`$, and exists **solely** at $`(2m, \varepsilon) = (8, +)`$ ($`n = 120`$) as Paige's $`M(2)`$.

## Hypotheses

Arbitrary loops $`(Q, *)`$ with $`\mathop{\mathrm{Mlt}}\nolimits(Q) \le P`$ in (1) and (2); left Bol hypothesis used only to deduce Moufang from RIP in (2). Completely CFSG-free.
