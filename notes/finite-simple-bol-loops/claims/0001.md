## Statement

Let $`(Q, *)`$ be a left Bol loop ($`x * (y * (x * z)) = (x * (y * x)) * z`$). Then:
1. **Inverses, properness, and Moufang obstruction**: $`Q`$ has unique two-sided inverses and the left inverse property ($`L_x^{-1} = L_{x^{-1}}`$); $`Q`$ is Moufang iff $`Q`$ has RIP iff $`Q`$ has AAIP iff $`Q`$ is right Bol (so $`Q \not\cong Q^{\mathrm{op}}`$ for every proper left Bol loop); every right Bol folder $`(G, H, K)`$ with $`K^{-1} = K`$ defines a left Bol loop $`(K, *_{\mathrm{L}}) \cong (K, \circ_{\mathrm{R}})^{\mathrm{op}}`$ via left cosets on the identical $`(G, H, K)`$; and for any simple nonassociative Moufang loop $`Q`$, $`\mathop{\mathrm{LMlt}}\nolimits(Q) = \mathop{\mathrm{RMlt}}\nolimits(Q) = \mathop{\mathrm{Mlt}}\nolimits(Q)`$ acts primitively on $`Q`$.
2. **Folder equivalence and exact isomorphism bijection**: Aschbacher–Nagy left Bol folders `(F1)–(F2)` coincide with single-stabilizer folders `(B1)–(B4)` (with `(B4)` and `(F2)` automatic from `(B1)–(B3)` whenever $`[G : H] < \infty`$). Every left Bol loop $`Q`$ admits a canonical faithful left Bol folder $`\mathcal{F}(Q) = (\mathop{\mathrm{LMlt}}\nolimits(Q), \mathop{\mathrm{LInn}}\nolimits(Q), \{L_x : x \in Q\})`$ ($`G = \langle K \rangle`$, $`\mathop{\mathrm{Core}}\nolimits_G(H) = 1`$), restriction $`\Phi \mapsto \Phi|_K`$ is a bijection $`\mathop{\mathrm{Iso}}\nolimits_{\mathbf{BolFld}}(\mathcal{F}_1, \mathcal{F}_2) \xrightarrow{\sim} \mathop{\mathrm{Iso}}\nolimits_{\mathbf{Loop}}(Q_1, Q_2)`$ with $`\mathop{\mathrm{Aut}}\nolimits(Q) \cong N_{\mathop{\mathrm{Aut}}\nolimits(G)}(H) \cap \mathop{\mathrm{Stab}}\nolimits_{\mathop{\mathrm{Aut}}\nolimits(G)}(K)`$, and $`(K, *)`$ is Moufang iff $`|K \cap x y H \cap H x y| = 1`$ for all $`x, y \in K`$.
3. **Nuclei and exact normal-subloop criterion**: Unconditionally $`N_\lambda(Q) = N_\mu(Q) \trianglelefteq Q`$ (hence $`N_\lambda(Q) = N_\mu(Q) = \{1\}`$ when $`Q`$ is simple proper), while $`N_\rho(Q) = K \cap N_G(H) \cong N_G(H) / H`$ satisfies $`|N_\rho(Q)| \mid |Q|`$ and $`|N_\rho(Q)| \le |Q| / 3`$ for finite simple proper $`Q`$. Moreover, for $`|Q| \ge 2`$, $`Q`$ is simple iff $`\mathop{\mathrm{Mlt}}\nolimits(Q)`$ is primitive on $`Q`$, and in a faithful folder $`(G, H, K)`$ an intermediate subgroup $`H \le U \le G`$ defines a normal subloop $`P_U = K \cap U \trianglelefteq Q`$ iff $`U = H N`$ ($`N = \mathop{\mathrm{Core}}\nolimits_G(U)`$) and $`K N / N`$ is a left transversal to $`H N / N`$ in $`G / N`$ (for $`[G : H N] < \infty`$, $`|K N / N| = [G : H N]`$), with $`(G/N, H N/N, K N/N)`$ the faithful folder of $`Q / P_U`$. In particular, the naive converse of Nagy `N07` Lemma 2.2 fails on $`Q_{24}`$ ($`N = V_4 \times V_4 \trianglelefteq G`$ is $`\sigma`$-invariant and intransitive with $`[G : H N] = 3 < 6 = |K N / N|`$).

## Hypotheses

All loops in (1)–(3) satisfy the left Bol identity; finiteness is assumed only where $`[G : H] < \infty`$ or $`|Q| < \infty`$ is explicitly stated.
