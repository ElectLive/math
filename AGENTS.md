# Public math repository

This repository holds public mathematical exposition and authorized research
mirrors. Research iteration and agent-owned research PR workspaces belong in
`Mira-Cult/math-wip` unless the task explicitly assigns work here.

Use the [public-writeup skill](.agents/skills/public-writeup/SKILL.md) for an
assigned public-publication, mirroring or public-workspace organization pass.
Preserve exact mathematical scope, source and review provenance, existing public
URLs, third-party attribution, and active work. Reading the skill does not itself
authorize publication or require a new PR. Follow the coordinator's assigned
publication workflow; batch rendering checks for the actual publication checkpoint,
not every intermediate source edit. Standing authorized mirroring remains in force.
